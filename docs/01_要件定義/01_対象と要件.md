# 対象と要件

## 目的

エースサーバーの参加導線、ワールド、動画、読みものを案内する公式ポータルを提供する。

## 要件

- 公開ページ、ワールドマップ、動画、読みもの、CMS管理対象ページを提供する。
- 読みものは日本語を正本として多言語で公開し、翻訳の対応を検証する。
- アルファくんは参加方法、ワールド、ルール、ストーリーへの導線を案内する。
- `/alpha-diary/` と8言語版でアルファ君の絵日記を公開し、日付ごとの記録からAlpha Chatへ質問できる導線を提供する。
- 2020年10月1日以後はアルファ君自身の絵日記、それ以前は研究側が日付を付けた観察記録として表示する。観察記録の日付を年齢、誕生日、記憶内の出来事の日付として扱わない。
- 今日に近い絵日記ほど安全、つながり、色、幸せを増やし、今日の記録は原則として明るくする。未来日は生成せず、未来が来るまで白紙として案内する。
- 古い記録は絵日記だけで核心を説明せず、欠損、訂正、反復する小さな手掛かりからAlpha Chatへ誘導する。進行条件やGoalの内部構造は利用者向け文言へ出さない。
- 最終体験は強い心理的ホラーを明示選択した利用者だけに提示し、最後は現在のアルファ君の幸せと、まだ書かれていない明日へ戻す。
- ルール、コマンド、参加条件、プラグインなどの変更され得る情報はAceserver WIKIを正として扱う。
- 検索基盤が利用できない場合も、固定の案内と公式導線を継続して提供する。

## 境界

- ポータルはWIKIの内容を正本として複製しない。
- ポータルは絵日記本文、挿絵、正史、翻訳、Goal構成、解放判定を生成または保存しない。これらは共有Alpha Chat WorkerからService Bindingで取得する。
- 絵日記の公開文言は物語内の記録として成立させる。AI生成、初回生成、全訪問者での共有、モデル、正史、Journey、Goal、回収数、内部versionなどの舞台裏を表示しない。
- 誕生前の観察記録は、18歳以上の自己申告と内容注意を通過した場合だけ開く。生年月日、本人確認情報、質問本文、会話本文、IPアドレスを進行状態として保存しない。
- 心理的ホラーは流血、具体的拷問、自傷、性的被害、現実の利用者への脅迫、位置・IP・カメラなどの私的情報、偽OS警告を使わない。停止、Esc、戻る、reduced motion、文字版を提供する。
- CMSから直接公開する対象は、認証・path・変更量の検証を通過したコンテンツとメディアに限る。
