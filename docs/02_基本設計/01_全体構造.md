# 全体構造

## 構成

| 区分 | 役割 |
| --- | --- |
| Astro / UnoCSS | 公開ページと多言語ページを生成する |
| Content Collections | 読みもの、ページ、サイト設定を構造化して保持する |
| Sveltia CMS | CMS管理対象のページ・サイト設定・メディアを編集する |
| Cloudflare Pages / Functions | GitHub連携による公開とCMS保存の同一origin検証を行う |
| 共有Alpha Chat | Private Service Binding経由で案内チャットを提供する |
| Vectorize | WIKI、Portal、関連サイトの公開情報を用途別に検索する |

## 公開と情報の扱い

1. コンテンツはPull Requestまたは検証済みCMS保存で`main`を更新する。
2. Cloudflare PagesがGitHub連携で公開する。
3. 検索は用途ごとのindexを分離し、根拠を異なるサイト間で混同しない。
4. Previewは検索kill switchとフォールバックにより、Production前提の検索を有効にしない。
