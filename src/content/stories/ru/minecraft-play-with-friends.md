Прежде чем выбирать место для игры в Minecraft с друзьями, убедитесь, что все могут использовать одну редакцию: **Java Edition или Bedrock Edition**. В этом руководстве сравниваются свой мир, Realms и публичные серверы, а также объясняется выбор для ПК, Switch и мобильных игроков.

## Сначала проверьте: Java и Bedrock не играют вместе по умолчанию

### Java Edition играет с Java Edition

Java Edition — это главным образом редакция для ПК с Windows, macOS и Linux. В миры, Realms и серверы Java входят игроки Java. Даже если у друга есть Minecraft на ПК, клиент Bedrock не сможет по умолчанию войти в Java-направление.

### Bedrock Edition играет с Bedrock Edition

Bedrock Edition используется на ПК Windows, Switch, телефонах и консолях. Если в группе есть игрок на Switch или телефоне, сначала подтвердите, что все используют Bedrock. Официальные [требования к мультиплееру](https://help.minecraft.net/hc/en-us/articles/35930809028749-Requirements-to-Play-Minecraft-Multiplayer-Games) говорят, что установленная редакция должна совпадать с местом подключения.

![Группа Java на ПК и группа Bedrock с ПК, портативной консолью и телефоном в отдельных блочных мирах](/uploads/stories/minecraft-play-with-friends-editions.webp)

_Сначала все должны выбрать Java или все Bedrock: по умолчанию эти группы разделены._

## Четыре проверки перед входом

1. **Используйте одну редакцию.** Сначала решите, будет ли группа играть в Java или Bedrock. Не считайте вход между Java и Bedrock обычным условием.
2. **Обновите игру.** Разница версий может помешать появлению мира или входу игрока даже в одной редакции.
3. **Проверьте учётные записи и условия онлайн-игры.** Для онлайн-игры или кроссплея Bedrock со Switch или мобильным устройством каждый игрок входит в учётную запись Microsoft внутри Minecraft. Switch также использует Nintendo Account и Nintendo Switch Online; Android — учётную запись Google; iPhone и iPad — Apple ID. Роль каждой учётной записи указана в официальной [таблице учётных записей и редакций](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft) Minecraft.
4. **Проверьте детские учётные записи.** Разрешение на мультиплеер, которым управляет родитель, может блокировать приглашения и вход. Настройки конфиденциальности Microsoft/Xbox действуют и при игре на Switch или мобильном устройстве. Никогда не делитесь паролями; проверяйте конфиденциальность вместе с родителем или опекуном.

![Друзья за ПК, портативной консолью и телефоном проверяют один и тот же блочный мир, обновление, учётную запись и безопасность](/uploads/stories/minecraft-play-with-friends-checklist.webp)

_Совместная проверка редакции, обновления, учётной записи и детских настроек до игры помогает избежать многих проблем со входом._

Если эти пункты уже проверены, но войти всё ещё не удаётся, прочитайте [что проверить, если не получается войти на сервер Minecraft](/ru/stories/minecraft-server-cannot-join/), чтобы последовательно найти причину.

## Выбор между своим миром, Realms и публичным сервером

| Вариант          | Подходит для                                | Состояние хоста                                           | Что проверить перед игрой                                        |
| ---------------- | ------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------- |
| Свой мир         | Небольшая группа играет сегодня             | Другие входят, пока владелец держит мир открытым          | Одна редакция, условия LAN или приглашения                       |
| Realms           | Друзья входят в один мир в разное время     | При активной подписке приглашённые входят и без владельца | Java или Bedrock Realm, приглашение, подписка                    |
| Публичный сервер | Долгая игра в сообществе с другими игроками | Миром управляет оператор                                  | Поддерживаемая редакция, вход, правила, возраст и текущий статус |

![Слева направо: небольшая группа в своём мире, общий мир, куда можно зайти в любое время, и площадь публичного сервера с игроками](/uploads/stories/minecraft-play-with-friends-modes.webp)

_Слева направо: свой мир, Realms и публичный сервер. Выбирайте по размеру группы, времени и желаемому общению с сообществом._

### 1. Свой мир: начните с небольшой группы

Для друзей в одном доме или месте простой первый вариант — открыть мир по LAN. В Bedrock используйте совместимые устройства в одной локальной сети и включите у хоста мультиплеер и видимость LAN. Официальное [руководство по Bedrock LAN](https://help.minecraft.net/hc/en-us/articles/35697355112717) объясняет, как найти мир после подключения к одной сети.

Онлайн-приглашение друзей всё равно использует открытый мир хоста. Это подходит двум людям, которые хотят начать строить сегодня или проверить, нравится ли группе один стиль игры. Когда хост закрывает мир, остальные не могут в него войти, поэтому планируйте по его времени игры.

### 2. Realms: играть, когда владельца нет

Realms — официальный платный хостинг Minecraft. Пока подписка активна, приглашённые друзья могут войти, даже если владелец не запускает игру. Java Realms и Bedrock Realms разделены, поэтому выбирайте вариант для своей группы. Для Java смотрите официальное [руководство по созданию Java Realm](https://help.minecraft.net/hc/en-us/articles/4409253767821-How-to-Create-a-Minecraft-Java-Edition-Realm), для Bedrock — официальное [руководство по ссылкам-приглашениям Bedrock Realm](https://help.minecraft.net/hc/en-us/articles/36974952310925-Manage-Invite-Links-for-Minecraft-Bedrock-Edition-Realms).

Это хороший вариант для друзей с разным расписанием учёбы, работы или кружков, которые хотят постепенно улучшать общую базу. Не размещайте ссылку-приглашение там, где её увидит любой человек; отключайте или удаляйте её, когда она больше не нужна.

### 3. Публичные серверы: присоединиться к сообществу

Публичный сервер — это онлайн-мир под управлением оператора. Он может подойти тем, кто хочет строить, жить или участвовать в событиях с незнакомыми игроками. Перед входом проверьте правила, поддерживаемые редакцию и версию, возрастные условия и использование голосового чата или Discord.

Игрокам Switch особенно важно прочитать указания сервера о поддерживаемых устройствах и способе входа. Не рассчитывайте на неофициальное решение для подключения. Даже если сервер заявляет поддержку Java и Bedrock, фактические условия и версии зависят от этого сервера.

Как распознать сервер, который принимает обе редакции, подробно объясняет материал [могут ли Java и Bedrock играть вместе](/ru/stories/minecraft-java-bedrock-crossplay/).

## Начало игры на Java, Bedrock, Switch и мобильном устройстве

### Java Edition на ПК

Когда все используют Java Edition, выберите LAN-мир, Java Realm или публичный Java-сервер. Перед отправкой приглашения подтвердите, что друзья запустили Java Edition и версии игры совпадают.

### Bedrock Edition на ПК

Игроки Windows PC с Bedrock могут быть в одной группе с Bedrock-игроками на Switch и телефонах. Выберите короткую сессию в своём мире, постоянный Realm или публичный сервер по времени и цели группы.

### Nintendo Switch

Minecraft на Switch — это Bedrock Edition. Для игры с друзьями через интернет нужны Nintendo Account, привязанная к пользователю Switch, и активная подписка Nintendo Switch Online. Чтобы использовать кроссплей, друзей Minecraft, Realms и онлайн-мультиплеер, также войдите и привяжите учётную запись Microsoft в Minecraft. Nintendo Account/Nintendo Switch Online и учётная запись Microsoft имеют разные роли; одно не заменяет другое.

Локальная связь между находящимися рядом Switch не использует Nintendo Switch Online, но она отличается от входа через интернет. Чтобы играть на расстоянии с другом на телефоне или ПК, все должны использовать Bedrock и проверить учётную запись Microsoft каждого игрока и подписку на Switch.

### Телефон или планшет

Minecraft на мобильных устройствах также использует Bedrock Edition. Android использует учётную запись Google, а iPhone и iPad — Apple ID. Кроме того, войдите в учётную запись Microsoft внутри Minecraft для кроссплея, друзей Minecraft, Realms и онлайн-мультиплеера. Телефонам и планшетам не нужна консольная онлайн-подписка вроде Nintendo Switch Online; покупка приложения и расходы на передачу данных оплачиваются отдельно. Если сначала провести короткую LAN-сессию в домашнем Wi-Fi, будет проще найти проблему до перехода в Realms или на публичный сервер.

## Учётные записи и онлайн-подписки для Switch и мобильных устройств

Switch и мобильные устройства используют Bedrock Edition. Если все используют одну и ту же текущую обычную версию Bedrock и входят в учётную запись Microsoft, игроки Bedrock на Switch, Android, iPhone/iPad и Windows PC могут играть друг с другом. Друг с Java Edition не сможет войти в тот же мир только с помощью стандартных функций игры.

| Устройство                  | Учётная запись платформы | Учётная запись в Minecraft для кроссплея и онлайн-игры | Дополнительная онлайн-подписка                                                                                  |
| --------------------------- | ------------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Nintendo Switch             | Nintendo Account         | Войти и привязать учётную запись Microsoft             | Для онлайн-игры через интернет нужна Nintendo Switch Online. Для локальной связи между близкими Switch не нужна |
| Телефон или планшет Android | Учётная запись Google    | Войти в учётную запись Microsoft                       | Консольная онлайн-подписка не нужна                                                                             |
| iPhone или iPad             | Apple ID                 | Войти в учётную запись Microsoft                       | Консольная онлайн-подписка не нужна                                                                             |

На Switch и мобильных устройствах учётная запись Microsoft отличается от учётной записи для получения игры; она включает друзей, кроссплей, Realms и онлайн-мультиплеер. Подробнее смотрите в официальной [таблице учётных записей](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft), [инструкции по привязке на Switch](https://help.minecraft.net/hc/en-us/articles/4408894129933-Sign-in-to-Minecraft-with-a-Microsoft-Account-on-Nintendo-Switch), [инструкции по входу на мобильном устройстве](https://help.minecraft.net/hc/en-us/articles/31514831369869) и объяснении Nintendo об [онлайн-игре](https://support.nintendo.com/jp/nso/services/onlineplay/index.html).

### Пригласить друга Bedrock

1. Все запускают последнюю обычную версию Bedrock и входят в учётную запись Microsoft внутри Minecraft. При поиске друга проверяйте Xbox gamertag, а не только отображаемое имя.
2. Хост включает Многопользовательскую игру в настройках нужного мира, выбирает Друзья или Друзья друзей для доступа игроков и открывает мир.
3. Хост открывает Социальное меню в игре и выбирает Пригласить в игру; приглашённый принимает полученное приглашение. Игрок, который входит на Switch из другого места, также проверяет активность Nintendo Switch Online.

Названия экранов и уведомления могут отличаться по устройствам и обновлениям. Если есть сомнения, следуйте официальной [инструкции Minecraft по приглашению в мир Bedrock](https://help.minecraft.net/hc/en-us/articles/32899440702477).

### Родительские настройки для детской учётной записи

Родительские настройки Microsoft/Xbox действуют для Minecraft на Switch и мобильных устройствах даже без консоли Xbox. Родитель выбирает учётную запись Microsoft ребёнка и проверяет как минимум следующее.

- **Присоединяться к многопользовательским играм / Присоединяться к мультиплееру на Xbox:** Разрешите, чтобы входить в мультиплеер, Realms и другие серверы.
- **Присоединяться к кросс-сетевой игре:** Разрешите, чтобы играть с людьми на других игровых платформах, включая Switch и мобильные устройства.
- **Добавлять друзей и следовать за другими:** Разрешите, чтобы находить друга и приглашать его из списка друзей Minecraft.
- **Голосовое, текстовое общение и приглашения:** Выберите разрешённый для семьи диапазон.

После изменения выйдите из Minecraft, закройте игру и запустите её снова. Родительские ограничения или ограничения использования на Switch и телефоне задаются отдельно; если настройки Microsoft недостаточно, проверьте с родителем и устройство. Названия пунктов могут изменяться; приоритет имеет официальная [настройка мультиплеера для детской учётной записи](https://help.minecraft.net/hc/en-us/articles/24302916594701-Managing-Multiplayer-Game-Access-for-a-Child-Account-in-Minecraft) Minecraft.

## Если Switch или мобильное устройство не подключается

Проверка в таком порядке помогает отделить проблему учётной записи от проблемы сети.

1. **Редакция и обновление:** Убедитесь, что все используют Bedrock и одну и ту же последнюю обычную версию. Если используется предварительная или старая версия, сначала обновитесь и попробуйте обычную.
2. **Настройки мира хоста:** Убедитесь, что Многопользовательская игра и доступ игроков включены, а хост находится в сети для личного мира. Для Realms также проверьте подписку владельца и открыто ли Realm.
3. **Учётная запись Microsoft и родительские настройки:** Убедитесь, что каждый вошёл в правильную учётную запись Microsoft и что детской учётной записи разрешены мультиплеер, кросс-сетевая игра и добавление друзей.
4. **Подписка только для Switch:** Участнику на Switch, играющему через интернет, нужны активные Nintendo Account и Nintendo Switch Online. Телефону эта подписка не нужна.
5. **Подключение:** Перезапустите Minecraft и устройство, затем проверьте обычное интернет-подключение. Присоединяющемуся игроку не нужно случайно открывать порты маршрутизатора. Если вы меняли VPN или собственный DNS, верните обычную конфигурацию перед проверкой.

Если показано «Мультиплеер отключён», сначала проверьте конфиденциальность или родительские настройки Microsoft/Xbox. Если приглашение не приходит или мир не появляется, проверьте редакцию, настройки хоста и учётную запись Microsoft. Если подключиться всё ещё не удаётся, используйте официальное [устранение проблем подключения Bedrock-мультиплеера](https://help.minecraft.net/hc/en-us/articles/4409236107789-Minecraft-Bedrock-Edition-Multiplayer-Connectivity-Issues) и материал [что проверить, если не получается войти на сервер Minecraft](/ru/stories/minecraft-server-cannot-join/). При обращении за помощью укажите редакцию, устройство, версию игры, показанную ошибку и время попытки; никогда не сообщайте пароль или код аутентификации.

## Быстрый выбор

- **В группе есть игроки Switch или мобильных устройств:** все используют Bedrock.
- **У всех есть Java Edition на ПК:** выберите Java-мир, Realm или сервер.
- **Хотите продолжать без хоста:** рассмотрите Realms.
- **Хотите познакомиться с новыми игроками:** выберите публичный сервер после чтения правил и поддерживаемой редакции.

Некоторые серверы предоставляют собственную дополнительную систему кроссплея Java и Bedrock. Это не стандартная гарантия только по устройствам, поэтому подтвердите текущую поддержку в официальном руководстве места назначения.

Если группа хочет сама поддерживать мир, доступный постоянно, перед выбором между LAN, выделенным сервером и Realms прочитайте [как создать бесплатный сервер Minecraft](/ru/stories/minecraft-server-setup/).

Выбрав публичный сервер, сначала проверьте текущую точку входа на [портале Aceserver](/ru/), затем прочитайте актуальные правила и инструкции в [официальном Discord](https://discord.gg/acsv) и [официальном WIKI](https://asv-wiki.acecore.net). Эта статья не копирует изменчивые данные подключения; источником истины служат официальные инструкции.

Приглашая друзей, сначала подтвердите одну редакцию, прочитайте правила до входа и никогда не передавайте данные учётной записи. Чтобы сначала сравнить публичные серверы, посмотрите [как выбрать сервер Minecraft](/ru/stories/minecraft-server-osusume/).
