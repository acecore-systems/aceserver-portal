Прежде чем выбирать место для игры в Minecraft с друзьями, убедитесь, что все могут использовать одну редакцию: **Java Edition или Bedrock Edition**. В этом руководстве сравниваются свой мир, Realms и публичные серверы, а также объясняется выбор для ПК, Switch и мобильных игроков.

## Сначала проверьте: Java и Bedrock не играют вместе по умолчанию

### Java Edition играет с Java Edition

Java Edition — это главным образом редакция для ПК с Windows, macOS и Linux. В миры, Realms и серверы Java входят игроки Java. Даже если у друга есть Minecraft на ПК, клиент Bedrock не сможет по умолчанию войти в Java-направление.

### Bedrock Edition играет с Bedrock Edition

Bedrock Edition используется на ПК Windows, Switch, телефонах и консолях. Если в группе есть игрок на Switch или телефоне, сначала подтвердите, что все используют Bedrock. Официальные [требования к мультиплееру](https://help.minecraft.net/hc/en-us/articles/35930809028749-Requirements-to-Play-Minecraft-Multiplayer-Games) говорят, что установленная редакция должна совпадать с местом подключения.

## Четыре проверки перед входом

1. **Используйте одну редакцию.** Сначала решите, будет ли группа играть в Java или Bedrock. Не считайте вход между Java и Bedrock обычным условием.
2. **Обновите игру.** Разница версий может помешать появлению мира или входу игрока даже в одной редакции.
3. **Проверьте учётные записи и условия онлайн-игры.** Для мультиплеера на Switch, мобильных устройствах и других платформах требуется вход в учётную запись Microsoft или её привязка. Проверьте каждое устройство в официальной [таблице учётных записей и редакций](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft). Для онлайн-мультиплеера на консолях также нужна онлайн-подписка платформы.
4. **Проверьте детские учётные записи.** Разрешение на мультиплеер, которым управляет родитель, может блокировать приглашения и вход. Никогда не делитесь паролями; проверяйте конфиденциальность вместе с родителем или опекуном.

## Выбор между своим миром, Realms и публичным сервером

| Вариант          | Подходит для                                | Состояние хоста                                           | Что проверить перед игрой                                        |
| ---------------- | ------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------- |
| Свой мир         | Небольшая группа играет сегодня             | Другие входят, пока владелец держит мир открытым          | Одна редакция, условия LAN или приглашения                       |
| Realms           | Друзья входят в один мир в разное время     | При активной подписке приглашённые входят и без владельца | Java или Bedrock Realm, приглашение, подписка                    |
| Публичный сервер | Долгая игра в сообществе с другими игроками | Миром управляет оператор                                  | Поддерживаемая редакция, вход, правила, возраст и текущий статус |

### 1. Свой мир: начните с небольшой группы

Для друзей в одном доме или месте простой первый вариант — открыть мир по LAN. В Bedrock используйте совместимые устройства в одной локальной сети и включите у хоста мультиплеер и видимость LAN. Официальное [руководство по Bedrock LAN](https://help.minecraft.net/hc/en-us/articles/35697355112717) объясняет, как найти мир после подключения к одной сети.

Онлайн-приглашение друзей всё равно использует открытый мир хоста. Это подходит двум людям, которые хотят начать строить сегодня или проверить, нравится ли группе один стиль игры. Когда хост закрывает мир, остальные не могут в него войти, поэтому планируйте по его времени игры.

### 2. Realms: играть, когда владельца нет

Realms — официальный платный хостинг Minecraft. Пока подписка активна, приглашённые друзья могут войти, даже если владелец не запускает игру. Java Realms и Bedrock Realms разделены, поэтому выбирайте вариант для своей группы. Для Java смотрите официальное [руководство по созданию Java Realm](https://help.minecraft.net/hc/en-us/articles/4409253767821-How-to-Create-a-Minecraft-Java-Edition-Realm), для Bedrock — официальное [руководство по ссылкам-приглашениям Bedrock Realm](https://help.minecraft.net/hc/en-us/articles/36974952310925-Manage-Invite-Links-for-Minecraft-Bedrock-Edition-Realms).

Это хороший вариант для друзей с разным расписанием учёбы, работы или кружков, которые хотят постепенно улучшать общую базу. Не размещайте ссылку-приглашение там, где её увидит любой человек; отключайте или удаляйте её, когда она больше не нужна.

### 3. Публичные серверы: присоединиться к сообществу

Публичный сервер — это онлайн-мир под управлением оператора. Он может подойти тем, кто хочет строить, жить или участвовать в событиях с незнакомыми игроками. Перед входом проверьте правила, поддерживаемые редакцию и версию, возрастные условия и использование голосового чата или Discord.

Игрокам Switch особенно важно прочитать указания сервера о поддерживаемых устройствах и способе входа. Не рассчитывайте на неофициальное решение для подключения. Даже если сервер заявляет поддержку Java и Bedrock, фактические условия и версии зависят от этого сервера.

## Начало игры на Java, Bedrock, Switch и мобильном устройстве

### Java Edition на ПК

Когда все используют Java Edition, выберите LAN-мир, Java Realm или публичный Java-сервер. Перед отправкой приглашения подтвердите, что друзья запустили Java Edition и версии игры совпадают.

### Bedrock Edition на ПК

Игроки Windows PC с Bedrock могут быть в одной группе с Bedrock-игроками на Switch и телефонах. Выберите короткую сессию в своём мире, постоянный Realm или публичный сервер по времени и цели группы.

### Nintendo Switch

Minecraft на Switch — это Bedrock Edition. Перед онлайн-мультиплеером проверьте Nintendo Account, привязку учётной записи Microsoft, Nintendo Switch Online и обновление игры. Группе с игроком Switch обычно следует использовать Bedrock, а не Java.

### Телефон или планшет

Minecraft на мобильных устройствах также использует Bedrock Edition. На Android проверьте учётную запись Google, на iPhone и iPad — Apple ID, затем войдите или привяжите учётную запись Microsoft для мультиплеера. Если сначала провести короткую LAN-сессию в домашнем Wi-Fi, будет проще найти проблему до перехода в Realms или на публичный сервер.

## Быстрый выбор

- **В группе есть игроки Switch или мобильных устройств:** все используют Bedrock.
- **У всех есть Java Edition на ПК:** выберите Java-мир, Realm или сервер.
- **Хотите продолжать без хоста:** рассмотрите Realms.
- **Хотите познакомиться с новыми игроками:** выберите публичный сервер после чтения правил и поддерживаемой редакции.

Некоторые серверы предоставляют собственную дополнительную систему кроссплея Java и Bedrock. Это не стандартная гарантия только по устройствам, поэтому подтвердите текущую поддержку в официальном руководстве места назначения.

Выбрав публичный сервер, сначала проверьте текущую точку входа на [портале Aceserver](/ru/), затем прочитайте актуальные правила и инструкции в [официальном Discord](https://discord.gg/acsv) и [официальном WIKI](https://asv-wiki.acecore.net). Эта статья не копирует изменчивые данные подключения; источником истины служат официальные инструкции.

Приглашая друзей, сначала подтвердите одну редакцию, прочитайте правила до входа и никогда не передавайте данные учётной записи. Чтобы сначала сравнить публичные серверы, посмотрите [как выбрать сервер Minecraft](/ru/stories/minecraft-server-osusume/).
