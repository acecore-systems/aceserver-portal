Чтобы пригласить на собственный Java-сервер друзей, использующих Bedrock на телефонах, планшетах, Windows или консолях, практично установить на Java-сервер Geyser и Floodgate. Geyser связывает подключения Bedrock с Java-сервером, а Floodgate помогает серверу безопасно распознавать учётные записи Bedrock.

Важно не отключать проверку Java-учётных записей только ради доступа друзей с Bedrock. В этом руководстве сохраняются Java-аутентификация и режим только по приглашениям. Управление и некоторые возможности Java и Bedrock не полностью совпадают, поэтому до открытия сервера нужно проверить оба типа устройств.

Если вы ещё решаете, как друзьям на разных устройствах играть вместе, также прочитайте [как играть в Minecraft с друзьями](/ru/stories/minecraft-play-with-friends/).

## Кратко: один сервер с Java + Geyser + Floodgate

Для Java-сервера, которым вы управляете сами, понятная схема — Paper с поддержкой плагинов, Geyser и Floodgate на одном сервере.

- Друзья с Java входят через TCP-точку Java-сервера.
- Друзья с Bedrock входят через UDP-точку, которую слушает Geyser.
- Floodgate позволяет друзьям с Bedrock входить как учётным записям Bedrock без отдельной покупки Java Edition.
- Оставьте online-mode Java-сервера равным true.

Этот способ добавляет к Java-серверу путь подключения Bedrock. Он не позволяет Java-клиентам напрямую войти на сервер только для Bedrock и не связывает Realms Java и Bedrock между собой.

Если нужно понять, принимает ли существующий сервер обе редакции, прочитайте [могут ли Java и Bedrock играть вместе?](/ru/stories/minecraft-java-bedrock-crossplay/).

### Что проверить сначала

- Подготовьте ПК, который может запускать Java-сервер, либо хостинг с поддержкой серверных плагинов.
- Убедитесь, что каждый может законно войти в принадлежащее ему издание.
- Согласуйте поддерживаемые версии Java и Bedrock, установленные плагины и пакеты ресурсов.
- У консолей могут быть собственные правила ввода пользовательских серверов. Не используйте обходы с изменением DNS, а проверьте официальные инструкции для устройства и хостинга.

## Выберите способ начать бесплатно

Бесплатный сервер означает, что серверное ПО или бесплатный тариф хостинга не берёт плату за использование. Это не делает бесплатными Minecraft, хост-компьютер, электричество и интернет, резервные копии или работу по обновлению.

| ------------------------------------ | --------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |

| Домашний сервер, доступ из интернета | ПО бесплатно; ПК, интернет и электричество отдельно | Открывайте только Java TCP и Geyser UDP по необходимости                  | Сначала настройте список допуска, системный брандмауэр и резервные копии                             | Роутер, IPv6 и обновления нужно администрировать самостоятельно |

Если вы не уверены в открытии портов дома, сначала подтвердите конфигурацию в LAN или начните с бесплатного хостинга, который управляет внешним адресом и портом. На момент написания статьи официальное руководство Aternos рекомендует Paper и описывает автоматическую установку и настройку Floodgate при установке Geyser. Если панель или политика изменились, следуйте актуальной официальной инструкции.

Для базового сравнения бесплатных вариантов Java, Bedrock и Realms также прочитайте [как создать бесплатный сервер Minecraft](/ru/stories/minecraft-server-setup/).

## Поймите структуру подключения

Java и Bedrock достигают сервера в разных сетевых форматах. Когда Geyser и Floodgate установлены на одном Paper-сервере, у каждого подключения своя роль.

| Кто подключается | Назначение                                                 | Транспорт                   | Роль на сервере                                              |
| ---------------- | ---------------------------------------------------------- | --------------------------- | ------------------------------------------------------------ |
| Друзья с Java    | Адрес и порт Java-сервера                                  | TCP                         | Paper принимает подключение напрямую                         |
| Друзья с Bedrock | То же имя хоста и Bedrock-порт, предоставленный для Geyser | UDP                         | Geyser преобразует подключение для Paper                     |
| Администратор    | Консоль сервера или панель хостинга                        | Непубличный путь управления | Управляет списком допуска, резервными копиями и обновлениями |

На домашнем сервере обычно используются Java TCP 25565 и Geyser UDP 19132, но хостинг может назначить другие номера. Сообщайте друзьям с Bedrock UDP-порт Geyser, показанный в панели, а не просите их предполагать, что это 19132.

UDP-порт Geyser нельзя совместно использовать с голосовым чатом, Query или другой UDP-службой. Добавляя функцию позже, не принуждайте её использовать тот же порт: проверьте официальную документацию и распределение портов хостинга.

![Игрок Java за ПК подключается напрямую к защищённому дому сервера, а игроки Bedrock с планшетом, телефоном и портативной консолью проходят по синему мосту к тому же дому](/uploads/stories/minecraft-java-bedrock-shared-server-topology.webp)

_Java подключается к Paper напрямую; Bedrock сначала поступает в Geyser, который передаёт подключение тому же серверу Paper._

## Шаг 1: установите Paper, Geyser и Floodgate

1. Выберите Paper или другое Java-серверное ПО с поддержкой серверных плагинов. Один только vanilla Java-сервер не может загружать плагины семейства Bukkit.
2. Получайте Geyser и Floodgate из официальной поставки Geyser или из официальной панели дополнений вашего хостинга, в версиях, соответствующих серверу. Не используйте файлы неизвестного происхождения.
3. Один раз запустите сервер и подтвердите в консоли, что Geyser и Floodgate оба загрузились.
4. В конфигурации с плагином Paper Geyser может автоматически определить Java-назначение и аутентификацию Floodgate. Прежде чем вручную менять настройки, проверьте официальную настройку и руководство именно вашего хостинга.

MOD, которые требуется устанавливать только на клиенте, не могут работать у Bedrock-клиентов, входящих через Geyser. До приглашения всей группы проверьте установленные MOD, плагины и пакеты ресурсов небольшой группой в обоих изданиях.

## Шаг 2: задайте безопасные значения до публикации

Сначала включите Java-аутентификацию и список допуска в server.properties Paper. Названия могут отличаться в зависимости от версии сервера или панели хостинга, поэтому перед изменением проверьте текущее значение.

| Настройка         | Рекомендуемое значение | Причина                                                         |
| ----------------- | ---------------------- | --------------------------------------------------------------- |
| online-mode       | true                   | Аутентифицирует Java-подключения через учётные записи Minecraft |
| white-list        | true                   | Не пускает неприглашённых людей                                 |
| enforce-whitelist | true                   | Удаляет игроков, которых нет в списке допуска                   |
| enable-rcon       | false                  | Не открывает неиспользуемую удалённую консоль                   |
| enable-query      | false                  | Не добавляет неиспользуемый Query-слушатель                     |

Добавляйте друзей с Java в обычный список допуска. Для друзей с Bedrock используйте команду списка Floodgate с настоящим геймертегом человека. В игровом чате с правами администратора выполните **/fwhitelist add gamertag**; в консоли сервера хоста уберите начальный `/` и используйте **fwhitelist add gamertag**. Не угадывайте префикс имени для обычного списка и не оставляйте список отключённым во время проверки.

Давайте права администратора только тем, кому они действительно нужны. Не раздавайте друзьям полную конфигурацию сервера, файлы ключей Floodgate или данные для входа в хостинг. Делайте резервную копию перед изменением настроек или обновлением плагинов и игры и проверяйте, что её можно восстановить.

![Администратор проверяет список разрешений рядом со щитом, два узких синих пути проходят через стену к дому сервера, а отдельная административная дверь остаётся запертой](/uploads/stories/minecraft-java-bedrock-shared-server-safe-settings.webp)

_Разрешаются только пути Java и Geyser, подтверждённые после проверки; административный путь остаётся закрытым для интернета._

## Шаг 3: поэтапно откройте только необходимый трафик

Проведите проверки подключения до открытия внешнего доступа.

1. Войдите на Paper-сервер с хост-ПК или Java-клиента в той же LAN.
2. Войдите через Geyser с Bedrock-клиента в той же LAN, используя UDP-порт.
3. В обоих изданиях проверьте список допуска, точку появления, сундуки, чат и сохранение мира.
4. Только когда удалённым друзьям нужен доступ, разрешите Java TCP-порт и Geyser UDP-порт по отдельности в системном брандмауэре и роутере.
5. Проверьте подключение с одним другом из списка допуска из другой сети. connectiontest Geyser также может помочь подтвердить назначение.

Вам не нужны DMZ, перенаправление всех портов, отключённый брандмауэр или публикация панели управления либо RCON в интернете. Если хост доступен по IPv6, не считайте, что правила IPv4-перенаправления его защищают: подтвердите, что правило системного брандмауэра действует и для IPv6.

![Слева игроки с ПК и планшетом проверяют защищённый дом сервера, затем администратор сверяет щит у ворот, прежде чем справа подключается один удалённый друг](/uploads/stories/minecraft-java-bedrock-shared-server-staged-test.webp)

_Сначала проверьте обе редакции в LAN, затем подтвердите доступ с одним другом из списка разрешений в другой сети._

Если подключение всё ещё не удаётся после этих тестов, не расширяйте публичный доступ. Используйте [что проверить, если не получается войти на сервер Minecraft](/ru/stories/minecraft-server-cannot-join/), чтобы по порядку отделить редакцию, версию, учётную запись и сеть.

## Проверки при запуске с бесплатным хостингом

Те же принципы публичной области действуют и для бесплатного хостинга. Не нужно создавать перенаправление портов в домашнем роутере, но всё равно следует защищать учётную запись хостинга, список допуска и доступ к панели.

1. Создайте Java Paper-сервер по официальной инструкции хостинга.
2. Добавьте Geyser из официальной панели дополнений и подтвердите, что Floodgate установлен.
3. После запуска проверьте Java- и Bedrock-адрес и порт, показанные на экране Connect хостинга.
4. Подтвердите настройки аутентификации и списка допуска из шага 2, прежде чем передавать сведения о подключении друзьям по отдельности.
5. Когда выйдет новая версия Bedrock, проверьте официальные указания хостинга и Geyser на предмет необходимого обновления Geyser.

Условия работы, охват резервных копий, поддерживаемые дополнения и обработка остановки сервиса на бесплатном тарифе различаются у провайдеров и могут измениться. Не храните важный мир только на хостинге: создайте резервную копию в другом месте способом, разрешённым условиями и панелью.

## Настройки, которые не стоит рекомендовать

- Не устанавливайте online-mode в false только для доступа Bedrock. Официальный FAQ Geyser считает офлайн-режим без Floodgate опасным и неподдерживаемым.
- Не публикуйте сервер с отключённым списком допуска даже для единственной проверки. Используйте функцию списка Floodgate для игроков Bedrock.
- Не используйте DMZ, перенаправление всех портов, отключённый брандмауэр или автоматическую публикацию UPnP вместо поиска причины проблемы подключения.
- Не включайте RCON, Query, PROXY protocol или внешнюю панель управления на всякий случай. Рассматривайте их только если понимаете требуемую конфигурацию и можете ограничить публикацию.
- Не запускайте неизвестные плагины, плагины обхода аутентификации или непроверенную общую полную конфигурацию.

## Список перед приглашением друзей

- Java- и Bedrock-клиенты могут войти, выйти и снова войти в реальном тесте.
- На Java-сервере online-mode равен true и включён список допуска.
- Java-имена и Bedrock-геймертеги через Floodgate находятся каждый в правильном списке.
- В интернет открыты только Java TCP и Geyser UDP; RCON, Query и панель не публичны.
- Каждый друг получает отдельно адрес, порт и поддерживаемую версию своего издания.
- Есть актуальная резервная копия, а способ восстановления проверен до обновлений.

После подтверждения этих пунктов друзья с Java и Bedrock смогут начать играть в одном мире, сохраняя защиту аутентификации и границы публичного доступа.
