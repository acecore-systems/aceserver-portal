Игроки Java и Bedrock могут играть вместе на совместимом сервере. Если сервер принимает подключения обеих версий, друзья с Java на ПК и с Bedrock на телефонах или консолях смогут строить и отправляться в приключения на одном сервере.

Однако **не каждый сервер Java Edition поддерживает Bedrock Edition.** Java и Bedrock используют разные способы подключения, поэтому команде сервера необходимо подготовить способ принимать игроков Bedrock. Не делайте вывод только по надписи «сервер Java»: проверьте, указана ли поддержка обеих версий в официальном руководстве по входу.

## Java и Bedrock могут играть вместе на совместимом сервере

На сервере с кроссплеем Java и Bedrock игроки из разных версий могут войти на один и тот же сервер. Не нужно разделять компанию только потому, что друзья используют разные версии.

Версии игры, правила сервера и установленные функции всё же могут влиять на способ входа или доступное управление. Начните с информации о входе, которую поддерживает в актуальном состоянии команда сервера.

## Сервер Java не становится автоматически совместимым с Bedrock

Java и Bedrock используют отдельные клиенты и разные способы подключения. Чтобы принимать игроков Bedrock, серверу нужны совместимый путь подключения и настройки. Поэтому сервер, который публикует только адрес для Java, может не принимать прямое подключение из Bedrock.

Если сервер сообщает только «поддерживается Java Edition», не стоит предполагать, что игроки Bedrock тоже смогут войти. Если кто-то в вашей группе использует Bedrock, выберите сервер с явно указанной поддержкой обеих версий или спросите команду до входа.

## Три пункта для проверки совместимого сервера

### 1. В официальном руководстве названы обе версии?

Ищите на официальном сайте или в руководстве по входу формулировки вроде «поддерживаются Java и Bedrock» или «кроссплей Java/Bedrock». Если упомянута только Java или только Bedrock, безопаснее не предполагать, что другая версия сможет войти.

### 2. Есть ли инструкция по входу для Bedrock?

Проверьте, указывает ли сервер адрес, порт или шаги подключения для Bedrock. Даже если Java и Bedrock используют один адрес, Bedrock может требовать другой порт или порядок действий. Если инструкции нет, не решайте самостоятельно, что сервер поддерживается: спросите в официальном Discord или другом официальном канале.

### 3. Проверены ли последние объявления и правила?

Поддерживаемые версии, рекомендуемые версии игры и условия входа могут меняться. Не опирайтесь только на старое описание: проверьте актуальную информацию на официальном сайте, в объявлениях и в Discord. Чтение правил до входа также поможет друзьям встретиться в игре без лишних трудностей.

## Что подготовить перед игрой с друзьями

- Убедитесь, что у каждого игрока есть указанное для его версии место подключения и нужная версия игры.
- Прочитайте правила сервера, возрастные условия и шаги первого входа.
- Проверьте в официальном руководстве, нет ли функций, которые различаются по версиям, например текстур, управления или отображения.

Эти три проверки заранее помогут избежать ситуаций, когда войти не может только один человек или группа по ошибке использует разные адреса подключения.
