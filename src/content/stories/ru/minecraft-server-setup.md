Играть в Minecraft с друзьями можно несколькими способами. Подходящий вариант зависит от того, хотите ли вы начать без платы за хостинг, играть только когда все дома или держать мир доступным в любое время.

Сначала это руководство помогает выбрать Java или Bedrock Edition, а затем объясняет выбор между бесплатной частью запуска сервера, выделенным сервером на домашнем компьютере и Realms. Предполагается, что у каждого игрока есть легальная копия игры.

## Сначала решите три вопроса

### Издания и устройства игроков

Официальное программное обеспечение выделенного сервера предоставляется отдельно для Java Edition и Bedrock Edition. До начала выясните, используют ли все ПК, телефон или консоль, а также Java или Bedrock.

### Когда мир должен быть доступен

Мир хоста или домашний компьютер обычно доступен только пока работает хост. Если другие должны подключаться в отсутствие хоста, спланируйте постоянно работающий вариант и трудозатраты на его обслуживание.

### Кто может подключиться

Приватному миру для нескольких друзей нужны иные меры защиты, чем миру, открытому для всех. Публичная работа включает доступ администратора, управление участниками, обновления, резервные копии и правила.

## Как выбрать способ

| Способ                           | Подходит для                                              | Сначала проверьте                                         |
| -------------------------------- | --------------------------------------------------------- | --------------------------------------------------------- |
| Мультиплеер в одной сети         | Короткие сессии дома или рядом                            | Работает ли хост                                          |
| Выделенный сервер на домашнем ПК | Небольшой группы, желающей изучить настройку и управление | Время работы ПК, обновления, резервные копии и открытость |
| Realms                           | Игры по приглашениям с меньшим объёмом управления         | Издание, план и приглашения                               |
| Подключение к публичному серверу | Первого опыта в большом общем мире                        | Правила, возрастные требования и способ входа             |

Выражение бесплатный сервер не означает, что программное обеспечение, оборудование, электричество, трафик и обслуживание не требуют затрат. Если сервер работает дома, кроме цены заранее решите, кто будет реагировать на его остановку.

## Запуск выделенного сервера Java Edition

Для Java Edition есть официальное ПО выделенного сервера. На официальной странице указано, что оно предназначено для Java Edition, Java должна быть доступна из командной строки, а настройка может потребовать усилий.

Используйте более безопасный порядок:

1. Получите серверное ПО из официального источника.
2. Проверьте запуск и остановку в своей среде до внешнего открытия.
3. Определите способ резервного копирования данных мира.
4. Согласуйте издание и версию для небольшой группы, затем проверьте подключение.
5. Только при необходимости внешнего доступа осторожно настройте маршрутизатор и брандмауэр, управление участниками и права администратора.

## Запуск выделенного сервера Bedrock Edition

У Bedrock тоже есть официальное Dedicated Server Software. Официальное руководство предлагает ПО для Windows или Linux и вложенное руководство по использованию. Не предполагайте, что устройства или шаги подключения совпадают с Java Edition; следуйте инструкции для Bedrock.

В Bedrock на подключение могут влиять типы устройств, настройки учётной записи Microsoft и параметры онлайн-доступа детских учётных записей. Начните с небольшой приглашённой группы, чтобы легче диагностировать проблемы.

## Когда подходит Realms

Realms подходит для продолжительного мультиплеера с приглашёнными участниками. В отличие от обычного мира хоста, который заканчивается, когда владелец выходит из игры, он использует приглашения и подписку.

Это не бесплатный вариант, но он уменьшает работу по самостоятельному открытию и обслуживанию сервера. Перед подпиской проверьте издания игроков, нужный план и официальные шаги приглашения.

## Проверка перед открытием сервера

- Регулярно делайте резервные копии данных мира.
- Выдавайте права администратора только тем, кому они нужны.
- Для публичного сервера подготовьте правила участия и способ связаться с оператором.
- Перед обновлением игры или серверного ПО проверьте совместимость и резервные копии.
- Не делитесь без необходимости паролями, IP-адресами и административными сведениями.

Актуальные инструкции и загрузки смотрите на [странице загрузки сервера Java Edition](https://www.minecraft.net/en-us/download/server), в [руководстве Dedicated Server Software](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-) и [руководстве по входу в Bedrock Realms](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm).
