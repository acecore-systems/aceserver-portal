Играть в Minecraft с друзьями можно несколькими способами: использовать одну локальную сеть, запустить выделенный сервер на собственном компьютере или воспользоваться Realms. Выбор зависит от издания у всех игроков и от того, сколько работы по обслуживанию вы готовы выполнять.

Важно понимать: бесплатный сервер означает, что само серверное программное обеспечение предоставляется бесплатно. Игра Minecraft, компьютер, электричество, интернет, резервные копии и обновления от этого бесплатными не становятся. В этой статье рассматривается размещение официального программного обеспечения на собственном компьютере.

| --------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------- | ----------------------------------------------------- |
| Игра в одной сети                 | Без дополнительной платы за сервер                                                               | Игроки из одного дома или LAN          | Первой короткой проверки                              |
| Выделенный сервер Java Edition    | Официальное ПО бесплатно; компьютер, сеть и электричество оплачиваются отдельно                  | Игроки Java Edition                    | Обучения настройке и управлению на ПК                 |

Java Edition и Bedrock Edition — разные издания, поэтому игроки обычно не могут напрямую подключиться к одному и тому же серверу. Проверьте не только устройства — ПК, телефон или консоль, — но и то, используют ли все Java или Bedrock.

## Подготовка перед настройкой сервера

### 1. Проверьте издание у всех

Java Edition доступно для ПК с Windows, macOS и Linux. Bedrock Edition доступно на ПК с Windows, телефонах, консолях и других поддерживаемых устройствах. В Windows можно иметь доступ к обоим изданиям, но запуск неправильного издания не позволит войти на нужный сервер.

### 2. Выберите компьютер-хост

Компьютер, на котором работает выделенный сервер, поддерживает работу мира. Если он перейдёт в спящий режим или процесс сервера остановится, подключённые друзья не смогут продолжить игру. Заранее решите, кто будет следить за свободным местом, памятью, сетью, обновлениями и резервными копиями.

### 3. Решите, кто сможет подключаться

Если все находятся в одной LAN, нет необходимости открывать сервер в интернете. Для приглашения друзей из другого места может понадобиться настроить проброс портов на роутере и правила брандмауэра. В целях безопасности сначала протестируйте сервер на своём компьютере и в локальной сети, а затем расширяйте доступ.

![Домашний ПК готовит файлы сервера, а друзья подключаются к общему блочному миру](/uploads/stories/minecraft-server-setup-guide.webp)

## Как создать бесплатный сервер Java Edition

Для Java Edition существует официальный Java Edition Server. Программное обеспечение на официальной странице загрузки предназначено только для Java Edition и требует совместимой среды Java, доступной из командной строки.

### Основные шаги

1. Создайте пустую папку и скачайте файл`.jar` Java-сервера с официальной страницы.
2. Переименуйте скачанный файл в понятное имя, например `server.jar`. Если вы оставляете исходное имя, замените его в командах ниже.
3. Убедитесь, что Java доступна.

```text
java -version
```

4. Откройте папку сервера в командной строке и один раз запустите сервер.

```text
java -jar server.jar nogui
```

5. Прочитайте файл`eula.txt`, созданный при первом запуске. Меняйте его на`eula=true` только после согласия с содержанием, затем снова запустите сервер.
6. В`server.properties` настройте режим игры, сложность и список разрешённых игроков.
7. Сначала подключитесь через `localhost` или адрес в той же LAN и убедитесь, что мир корректно сохраняется.

Версия сервера и версии клиентов должны быть совместимы. Перед обновлением скопируйте папку мира и остановите сервер. Это снижает риск ошибок подключения и повреждения мира.

## Как создать бесплатный сервер Bedrock Edition

Для Bedrock Edition существует официальный Bedrock Dedicated Server. На официальной странице доступны файлы для Windows и Linux. Это отдельное программное обеспечение, не то же самое, что Java`.jar`, поэтому при игре друзей в Bedrock Edition выбирайте пакет Bedrock.

### Основные шаги

1. Скачайте Bedrock Dedicated Server с официальной страницы в пустую папку.
2. Распакуйте ZIP-архив и прочитайте приложенное руководство. В официальном пакете есть инструкции по установке и использованию.
3. Запустите сервер с помощью исполняемого файла или команды для вашей операционной системы. Нужные файлы мира создаются при запуске.
4. Проверьте настройки мира и список разрешённых игроков в`server.properties`. Если сервер должен оставаться закрытым, в приложенном руководстве найдите настройки вроде`allow-list=true`.
5. Сначала подключите клиент Bedrock из той же LAN и проверьте версию и способ подключения.

Официальная среда Bedrock Dedicated Server рассчитана на Windows или Linux. Даже если телефоны или консоли могут подключаться, настройки аккаунта и требования онлайн-сервиса конкретного устройства могут влиять на соединение. Клиент Java Edition не может напрямую подключиться к серверу только для Bedrock.

## Является ли Realms бесплатным сервером?

Realms — официальный частный облачный сервер Minecraft. Владельцу не нужно держать игру запущенной, чтобы мир оставался доступным, а подключаться могут только приглашённые участники. Это уменьшает объём работы с домашним компьютером, пробросом портов и обновлениями серверного ПО.

Однако Realms — это сервис по подписке, а не постоянно бесплатный вариант. Подходящим аккаунтам может быть доступна бесплатная пробная версия на 30 дней, но официальная информация предупреждает об автоматическом продлении после окончания пробного периода, если подписку не отменить. Перед оформлением проверьте издание, план, ограничение одновременных игроков и условия продления.

Realms также разделён по изданиям: игроки Java входят в Java Realm, а игроки Bedrock — в Bedrock Realm. Realms не даёт кросс-игру между двумя изданиями.

## Какой способ выбрать?

- Для быстрой проверки дома или в одной LAN проще всего использовать многопользовательскую игру внутри Minecraft.
- Для игроков Java на ПК, которые хотят изучить настройку и управление, подойдёт выделенный сервер Java.
- Для друзей с устройствами Bedrock можно рассмотреть Bedrock Dedicated Server.
- Если постоянный доступ важнее цены и хочется меньше обслуживания, Realms проще, но он не бесплатен.

Если вы выбираете домашний сервер, чтобы не платить за хостинг, заранее решите, кто перезапустит его после остановки и где будет храниться копия мира. Такая подготовка предотвращает многие проблемы после начала игры.

## Что проверить перед открытием сервера

![Блочная иллюстрация резервных копий, контроля доступа и приглашённых друзей, готовящих частный сервер](/uploads/stories/minecraft-server-setup-safety.webp)

- Регулярно создавайте резервные копии мира и проверяйте возможность восстановления.
- Выдавайте права оператора или администратора только тем, кому они необходимы.
- При игре с друзьями используйте список разрешённых игроков, а не открывайте сервер для всех.
- Настраивайте роутер и брандмауэр только при реальной необходимости внешнего доступа.
- Перед обновлением игры или серверного ПО проверьте совместимость версий и наличие резервной копии.
- Не распространяйте IP-адреса, пароли и административные сведения шире, чем нужно.

Актуальные требования и загрузки смотрите на официальной [странице загрузки Java-сервера](https://www.minecraft.net/en-us/download/server), в [руководстве по настройке Java-сервера](https://help.minecraft.net/hc/en-us/articles/360058525452-How-to-Setup-a-Minecraft-Java-Edition-Server), на [странице загрузки Bedrock-сервера](https://www.minecraft.net/en-us/download/server/bedrock), в [материалах о Dedicated Server](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-), на [официальной странице Realms](https://www.minecraft.net/en-us/realms) и в [сравнении Java и Bedrock](https://www.minecraft.net/en-us/article/java-or-bedrock-edition).
