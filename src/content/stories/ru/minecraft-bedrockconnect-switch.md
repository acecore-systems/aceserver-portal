Если вы хотите подключиться из Minecraft Bedrock Edition на Nintendo Switch к серверу, которого нет среди официальных избранных серверов, можно использовать BedrockConnect. Этот способ направляет DNS Switch на BedrockConnect, а избранный сервер используется как вход в список серверов Bedrock.

В руководстве описан путь с Switch на внешний сервер Bedrock, например Aceserver. Адреса и порты различаются у разных серверов, поэтому всегда проверяйте актуальные данные в официальных инструкциях нужного сервера.

BedrockConnect не является официальной функцией Minecraft или Nintendo. Это бесплатный проект с открытым исходным кодом, но перед использованием прочитайте [официальный README на GitHub](https://github.com/Pugmatt/BedrockConnect) и не используйте приложения или загрузки из посторонних репозиториев.

## Что позволяет BedrockConnect

В Minecraft на Switch нет обычного списка для прямого добавления произвольных внешних серверов. BedrockConnect использует DNS и избранный сервер как вход, чтобы открыть экран ввода сервера назначения.

1. Измените DNS-настройки Switch на BedrockConnect.
2. Откройте совместимый избранный сервер на вкладке «Серверы» в Minecraft.
3. Введите адрес и порт сервера назначения в BedrockConnect.
4. Перейдите из BedrockConnect на сервер назначения.

Одной смены DNS недостаточно, если сервер назначения не поддерживает Bedrock Edition. Значения DNS и экраны могут измениться, поэтому отдавайте приоритет актуальным инструкциям в [официальном README BedrockConnect](https://github.com/Pugmatt/BedrockConnect).

## Что подготовить заранее

- Nintendo Switch, на котором запускается Minecraft Bedrock Edition
- Minecraft и учетная запись Microsoft, готовые к онлайн-игре
- Адрес и порт Bedrock, опубликованные сервером назначения
- Текущие сетевые настройки, чтобы позже вернуть исходный DNS Switch

Чтобы подключиться к Aceserver, сначала проверьте актуальные инструкции на [портале Aceserver](/ru/) и в [официальном Discord](https://discord.gg/acsv). Источником изменяемой информации, такой как правила и привязка Discord после входа, является [WIKI Aceserver](https://asv-wiki.acecore.net).

## Шаг 1: вручную настроить DNS Switch

1. Откройте «Настройки системы» на Switch, выберите «Интернет» и откройте «Настройки Интернета».
2. Выберите подключенную сеть и откройте «Изменить настройки».
3. Измените «Настройки DNS» с «Автоматически» на «Вручную».
4. Введите текущие значения из официального README BedrockConnect. По состоянию на 6 августа 2026 года в руководстве указаны:
   - Основной DNS: `104.238.130.180`
   - Вторичный DNS: `8.8.8.8`

5. Сохраните настройки и выполните проверку подключения.

Эта настройка применяется к сетевому подключению Switch. После использования BedrockConnect вернитесь на тот же экран и снова установите для DNS значение «Автоматически».

## Шаг 2: открыть BedrockConnect в Minecraft

1. Запустите Minecraft и войдите через учетную запись Microsoft.
2. Откройте «Играть» и выберите вкладку «Серверы».
3. Подключитесь к одному из следующих избранных серверов:
   - Mineville
   - Lifeboat
   - Enchanted
   - Galaxite
   - The Hive

В официальном README BedrockConnect эти серверы указаны как совместимые с перенаправлением через DNS. При успешном подключении вместо обычного избранного сервера появится список BedrockConnect.

Если открывается обычный избранный сервер, проверьте значения DNS и попробуйте другой совместимый сервер. Также может помочь перезапуск игры или сетевого подключения.

## Шаг 3: добавить сервер назначения

Когда появится экран BedrockConnect, добавьте внешний сервер следующим образом.

1. Выберите `Connect to a Server`.
2. Введите домен или IP-адрес сервера назначения в поле `Server Address`.
3. Введите опубликованный сервером порт Bedrock в поле `Server Port`. Некоторые серверы используют `19132`, но всегда следуйте инструкции самого сервера.
4. Введите понятное имя в поле `Display Name`. Это необязательно.
5. Включите `Add to server list`, если хотите не вводить данные повторно.
6. Нажмите кнопку отправки, чтобы начать подключение.

Чтобы изменить сохраненную запись, откройте `Manage Server List`, выберите `Edit a Server`, а затем нужный сервер.

## Подключение к Aceserver

Aceserver — это публичный Minecraft-сервер, принимающий игроков Java Edition и Bedrock Edition. Однако адрес и порт, которые вводятся в BedrockConnect, могут измениться в зависимости от текущей работы сервера.

Проверяйте данные в таком порядке:

1. Посмотрите актуальную информацию о подключении на [портале Aceserver](/ru/).
2. Подтвердите текущие адрес и порт в [официальном Discord](https://discord.gg/acsv).
3. Введите эти значения в `Server Address` и `Server Port` BedrockConnect.
4. После входа ознакомьтесь в [WIKI Aceserver](https://asv-wiki.acecore.net) с правилами и необходимой привязкой Discord.

Не используйте повторно IP-адрес из старой статьи или снимка экрана. Если адрес изменился или сервер находится на обслуживании, следуйте объявлению в официальном Discord.

## Если подключение не работает

### Список BedrockConnect не появляется

- Убедитесь, что DNS Switch установлен в режим «Вручную».
- Проверьте основной и вторичный DNS на ошибки ввода.
- Проверьте актуальные DNS-значения в официальном README BedrockConnect.
- Попробуйте открыть BedrockConnect через другой совместимый избранный сервер.
- Перезапустите Minecraft и сетевое подключение Switch.

### Список появляется, но подключение к цели не происходит

- Убедитесь, что `Server Address` совпадает с текущей инструкцией сервера.
- Убедитесь, что `Server Port` относится к Bedrock, а не к Java Edition.
- Подтвердите, что сервер назначения принимает игроков Bedrock Edition.
- Проверьте официальные инструкции на наличие обслуживания или ограничений доступа.

### Вернуть исходные настройки

Откройте подключенную сеть в «Настройки системы» → «Интернет» → «Настройки Интернета», установите для DNS значение «Автоматически» и сохраните.

## Важные замечания

BedrockConnect не добавляет функцию в официальный список серверов. Это внешний сервис, который использует DNS для открытия списка BedrockConnect через избранный сервер. Обновления игры или изменения сервиса могут сделать этот способ нерабочим.

В официальном README BedrockConnect сказано, что неофициальные мобильные приложения с таким же названием не связаны с проектом. Если приложение просит установить программу или ввести данные учетной записи, сравните его с инструкциями [официального GitHub](https://github.com/Pugmatt/BedrockConnect).

## Итоги

DNS-метод BedrockConnect может помочь игрокам Switch подключаться к внешним серверам Minecraft Bedrock. Настройте DNS, откройте BedrockConnect через совместимый избранный сервер и введите адрес и порт назначения.

При подключении к Aceserver используйте актуальные данные с [портала Aceserver](/ru/), из [официального Discord](https://discord.gg/acsv) и [WIKI Aceserver](https://asv-wiki.acecore.net), а не старое фиксированное значение.
