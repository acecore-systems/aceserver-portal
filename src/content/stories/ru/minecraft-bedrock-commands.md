Команды Minecraft Bedrock помогают менять время и погоду, переходить к координатам и проверять мир. В этом руководстве собраны базовые примеры для личного мира или мира, где у вас есть права управления.

Публичные серверы могут запрещать команды всем, кроме администраторов. Перед использованием примера из этой статьи на публичном сервере всегда прочитайте его правила.

## Что проверить перед началом

Чтобы использовать многие команды в Bedrock, нужно включить читы для мира и убедиться, что у вас есть нужные права. При включении читов в этом мире нельзя получать достижения, поэтому принимайте это решение осознанно.

Если вы не знаете, что вводить, начните в чате с:

```mcfunction
/help
```

Если добавить имя команды, например /help effect, отобразится синтаксис, доступный в текущей игре. Обновления Bedrock могут менять синтаксис, поэтому используйте подсказки игры и /help как окончательную проверку.

## Часто используемые команды

### Установить дневное время

```mcfunction
/time set day
```

Используйте эту команду, когда наступает ночь или когда хотите проверить постройку при ярком свете. Можно также выбрать время вроде noon, если оно появляется в подсказках.

### Установить ясную погоду

```mcfunction
/weather clear
```

Этот пример останавливает дождь или грозу для лучшей видимости. Команды погоды влияют на весь мир, поэтому в общем мире сначала предупредите других игроков.

### Изменить собственный режим игры

```mcfunction
/gamemode creative @s
```

@s означает игрока, который выполняет команду. Чтобы вернуться назад, замените creative на survival. Перед большими изменениями в важном мире сделайте резервную копию.

### Телепортироваться к координатам

```mcfunction
/tp @s 0 80 0
```

Эта команда перемещает вас к X=0, Y=80, Z=0. Сначала убедитесь, что место назначения не пустое и не опасное, особенно при перемещении под землю или высоко над ней.

### Выдать себе предмет

```mcfunction
/give @s torch 64
```

Этот пример выдаёт вам 64 факела. Идентификаторы предметов и количество можно проверить по подсказкам ввода. Это полезно при подготовке инструментов в тестовом или приключенческом мире.

### Включить бесконечное ночное зрение

```mcfunction
/effect @s night_vision infinite 0 true
```

Используйте этот пример для проверки тёмных пещер или построек. Последнее true скрывает частицы. Чтобы снять эффект, используйте:

```mcfunction
/effect @s clear night_vision
```

## Если команда не работает

1. Проверьте, включены ли читы в личном мире или есть ли у вас права управления.
2. Проверьте текущий синтаксис через /help с именем команды и подсказки чата.
3. Не копируйте без изменений руководство для Java Edition. У Java и Bedrock могут быть разные синтаксис и условия для одной цели.
4. На публичном сервере сначала следуйте правилам и инструкциям этого сервера.

## Проверяйте по одной команде

Команды сильны тем, что могут сразу изменить мир. Начните в тестовом мире с резервной копией и пробуйте по одному понятные изменения: время, погоду и ночное зрение.

Синтаксис и права описаны во [введении в команды Bedrock на Microsoft Learn](https://learn.microsoft.com/en-us/minecraft/creator/documents/commandsintroduction?view=minecraft-bedrock-stable), [справочнике команд](https://learn.microsoft.com/en-us/minecraft/creator/commands/?view=minecraft-bedrock-stable) и [справочнике команды effect](https://learn.microsoft.com/en-us/minecraft/creator/commands/commands/effect?view=minecraft-bedrock-stable).
