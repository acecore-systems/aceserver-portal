Minecraft統合版のコマンドは、時間や天気を変えたり、座標へ移動したり、ワールドの検証をしたりするときに便利です。ここでは、個人ワールドまたは管理権限を持つワールドで使う基本的な入力例をまとめます。

公開サーバーでは、管理者以外のコマンドを禁止していることがあります。この記事の例を公開サーバーで試す前に、必ず各サーバーのルールを確認してください。

## 最初に確認すること

統合版で多くのコマンドを使うには、ワールドでチートを有効にし、自分に必要な権限を設定する必要があります。チートを有効にすると、そのワールドでは実績を獲得できなくなる点に注意してください。

入力に迷ったら、まずチャットで次を実行します。

```mcfunction
/help
```

「/help effect」のようにコマンド名を続けると、使える構文をその場で確認できます。統合版は更新で利用できる構文が変わることがあるため、入力候補と /help を最後の確認に使うのが安全です。

## よく使うコマンド

### 時間を朝にする

```mcfunction
/time set day
```

夜になってしまったときや、建築を明るい時間に確認したいときに使えます。day の代わりに noon など、入力候補に出る時刻指定も選べます。

### 天気を晴れにする

```mcfunction
/weather clear
```

雨や雷雨を止めて、視界を確認したいときの入力例です。天気を変えるコマンドはワールド全体に影響するため、複数人で遊んでいるときは先に共有すると安心です。

### 自分のゲームモードを変える

```mcfunction
/gamemode creative @s
```

@s はコマンドを実行した自分を指します。サバイバルに戻す場合は、creative を survival に置き換えます。大切なワールドでは、作業前にバックアップを取ってから使いましょう。

### 指定した座標へ移動する

```mcfunction
/tp @s 0 80 0
```

この例では、自分を X=0、Y=80、Z=0 へ移動します。目的地の下が空洞や危険な場所でないかを先に確認し、高所や地下へ移動する場合は特に慎重に使ってください。

### アイテムを受け取る

```mcfunction
/give @s torch 64
```

この例では、自分に松明を64個渡します。アイテムIDや数量は入力候補で確認できます。配布ワールドや検証ワールドで必要な道具を準備するときに便利です。

### 暗視を無期限で付ける

```mcfunction
/effect @s night_vision infinite 0 true
```

洞窟や建築の暗い場所を確認するときの例です。最後の true はパーティクルを非表示にする指定です。暗視を外す場合は次を使います。

```mcfunction
/effect @s clear night_vision
```

## うまく動かないときの確認順

1. 個人ワールドでチートが有効か、または自分に管理権限があるかを確認する。
2. 「/help コマンド名」とチャットの入力候補で、現在の構文を確認する。
3. Java版の解説をそのままコピーしていないかを確認する。Java版と統合版では、同じ目的でも構文や利用条件が異なることがあります。
4. 公開サーバーでは、そのサーバーのルールと案内を優先する。

## まずは一つずつ試そう

コマンドは便利ですが、ワールドの状態をすぐに変えられます。最初はコピーを取ったテスト用ワールドで、時間変更、天気変更、暗視のように影響範囲が分かりやすいものから試すのがおすすめです。

構文と権限の詳細は、[Microsoft Learnの統合版コマンド入門](https://learn.microsoft.com/en-us/minecraft/creator/documents/commandsintroduction?view=minecraft-bedrock-stable)、[コマンド一覧](https://learn.microsoft.com/en-us/minecraft/creator/commands/?view=minecraft-bedrock-stable)、[effectコマンドの仕様](https://learn.microsoft.com/en-us/minecraft/creator/commands/commands/effect?view=minecraft-bedrock-stable)で確認できます。
