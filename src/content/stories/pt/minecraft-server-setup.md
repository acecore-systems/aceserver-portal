Há mais de uma forma de jogar Minecraft com amigos. A melhor escolha depende de você querer começar sem pagar hospedagem, jogar apenas quando todos estiverem em casa ou manter um mundo disponível a qualquer hora.

Este guia começa pela escolha entre Java e Bedrock Edition e depois explica como escolher entre a parte gratuita de hospedar um servidor, um servidor dedicado em computador doméstico e Realms. Ele pressupõe que cada jogador possui uma cópia legítima do jogo.

## Decida estas três coisas primeiro

### Edições e dispositivos dos jogadores

O software oficial de servidor dedicado é fornecido separadamente para Java Edition e Bedrock Edition. Antes de começar, identifique se todos usam PC, celular ou console, e se usam Java ou Bedrock.

### Quando o mundo precisa estar disponível

Um mundo hospedado ou um computador doméstico costuma ficar disponível apenas enquanto o host está ligado. Se outras pessoas precisarem entrar quando o host estiver ausente, planeje uma opção sempre ativa e o trabalho necessário para operá-la.

### Quem pode entrar

Um mundo privado para poucos amigos precisa de proteções diferentes de um mundo aberto ao público. A operação pública inclui acesso de administração, gestão de participantes, atualizações, backups e regras.

## Como escolher um método

| Método                            | Melhor para                                           | Verifique primeiro                              |
| --------------------------------- | ----------------------------------------------------- | ----------------------------------------------- |
| Multijogador na mesma rede        | Sessões curtas em casa ou perto                       | Se o host está ligado                           |
| Servidor dedicado em PC doméstico | Grupo pequeno que quer aprender configuração e gestão | Tempo ligado, atualizações, backups e exposição |
| Realms                            | Jogo por convite com menos trabalho de gestão         | Edição, plano e convites                        |
| Entrar em servidor público        | Experimentar primeiro um mundo compartilhado maior    | Regras, idade e forma de entrada                |

A expressão servidor gratuito não significa que software, hardware, eletricidade, banda e manutenção sejam todos gratuitos. Se você executar em casa, decida quem responderá quando ele parar, além de quanto custa.

## Iniciar um servidor dedicado de Java Edition

Java Edition possui software oficial de servidor dedicado. A página oficial explica que ele é para Java Edition, que Java precisa poder ser usado pela linha de comando e que a configuração pode exigir trabalho.

Siga esta ordem mais segura:

1. Obtenha o software do servidor pela fonte oficial.
2. Confirme a inicialização e o desligamento no seu ambiente antes de expor externamente.
3. Defina como os dados do mundo serão copiados.
4. Combine edição e versão para um grupo pequeno e teste a entrada.
5. Só quando precisar de acesso externo, configure com cuidado roteador e firewall, gestão de participantes e permissões de administração.

## Iniciar um servidor dedicado de Bedrock Edition

Bedrock também tem Dedicated Server Software oficial. A orientação oficial oferece software para Windows ou Linux e um guia de uso incluído. Não suponha que dispositivos ou etapas de entrada sejam iguais aos do Java Edition; siga a orientação específica do Bedrock.

No Bedrock, tipos de dispositivo, configurações da conta Microsoft e opções online de contas infantis podem afetar a conexão. Comece com um pequeno grupo convidado para facilitar o diagnóstico.

## Quando Realms é adequado

Realms é uma opção para manter o multijogador com membros convidados. Diferentemente de um mundo comum hospedado que termina quando o proprietário sai do jogo, ele usa convites e uma assinatura.

Não é gratuito, mas reduz o trabalho de expor e manter um servidor por conta própria. Antes de assinar, confirme as edições dos jogadores, o plano necessário e as etapas oficiais de convite.

## Lista antes de abrir um servidor

- Faça backup dos dados do mundo regularmente.
- Dê acesso de administração apenas a quem precisar.
- Para um servidor público, prepare regras de participação e uma forma de falar com a pessoa operadora.
- Verifique compatibilidade e backups antes de atualizar o jogo ou o software do servidor.
- Não compartilhe senhas, endereços IP ou informações de administração sem necessidade.

Consulte a [página de download do servidor Java Edition](https://www.minecraft.net/en-us/download/server), a [orientação de Dedicated Server Software](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-) e o [guia para entrar em Realms Bedrock](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm) para downloads e instruções atuais.
