Jogadores de Java e Bedrock podem jogar juntos em um servidor compatível. Se o servidor aceita conexões das duas edições, amigos que usam Java no PC e pessoas que usam Bedrock no celular ou no console podem construir e se aventurar no mesmo servidor.

Porém, **nem todo servidor de Java Edition oferece suporte a Bedrock Edition.** Java e Bedrock usam métodos de conexão diferentes, então a equipe do servidor precisa preparar uma forma de receber jogadores de Bedrock. Não decida apenas porque está escrito “servidor Java”; confirme no guia oficial de entrada se há suporte declarado para as duas edições.

## Java e Bedrock podem jogar juntos em um servidor compatível

![Um notebook e um dispositivo portátil seguem caminhos luminosos para o mesmo mundo de servidor em blocos](/uploads/stories/minecraft-java-bedrock-crossplay-devices.webp)

Em um servidor com cross-play entre Java e Bedrock, jogadores de edições diferentes podem entrar no mesmo servidor. Não é preciso separar o grupo apenas porque os amigos usam edições diferentes.

Versões do jogo, regras do servidor e recursos instalados ainda podem afetar a forma de entrar ou os controles disponíveis. Comece pelas informações de entrada que a equipe do servidor mantém atualizadas.

## Um servidor Java não é automaticamente compatível com Bedrock

Java e Bedrock usam clientes separados e métodos de conexão diferentes. Para aceitar jogadores de Bedrock, o servidor precisa de uma rota de conexão e de configurações compatíveis. Por isso, um servidor que publica apenas um endereço Java pode não aceitar uma conexão direta do Bedrock.

Quando um servidor diz apenas “compatível com Java Edition”, não presuma que jogadores de Bedrock também possam entrar. Se alguém do grupo usa Bedrock, escolha um servidor que declare suporte às duas edições ou consulte a equipe antes de entrar.

## Três pontos para identificar um servidor compatível

![Uma pessoa aventureira em blocos confere mapa e placas antes de escolher uma entrada compatível](/uploads/stories/minecraft-java-bedrock-crossplay-check.webp)

### 1. O guia oficial menciona as duas edições?

Procure textos como “suporte a Java e Bedrock” ou “cross-play Java/Bedrock” no site oficial ou no guia de entrada. Se ele menciona apenas Java ou apenas Bedrock, é mais seguro não supor que a outra edição possa entrar.

### 2. Há instruções de entrada para Bedrock?

Verifique se o servidor fornece endereço, porta ou passos de conexão para Bedrock. Mesmo quando Java e Bedrock usam o mesmo endereço, Bedrock pode exigir outra porta ou procedimento. Se não encontrar instruções, não conclua sozinho que há suporte; pergunte pelo Discord oficial ou por outro canal oficial.

### 3. Você conferiu os avisos e as regras mais recentes?

As edições aceitas, as versões recomendadas e os requisitos de entrada podem mudar. Não se baseie apenas em uma apresentação antiga: confira as informações mais recentes no site oficial, nos avisos e no Discord. Ler as regras antes de entrar também ajuda o grupo a se encontrar sem problemas.

## O que preparar antes de jogar com amigos

- Confirme que cada jogador tem o destino de conexão e a versão do jogo indicados para sua própria edição.
- Leia as regras do servidor, os requisitos de idade e os passos para a primeira entrada.
- Consulte o guia oficial para ver se há recursos que diferem por edição, como texturas, controles ou exibição.

Fazer essas três verificações antes ajuda a evitar problemas como apenas uma pessoa não conseguir entrar ou o grupo usar destinos de conexão diferentes por engano.

Java e Bedrock podem jogar juntos quando um servidor oferece suporte a conexões das duas edições. Nem todo servidor de Java Edition aceita Bedrock, portanto confirme no guia oficial o suporte às duas edições, o método de entrada do Bedrock e as regras mais recentes antes de escolher um servidor.
