Java and Bedrock players can play together on a compatible server. If the server accepts connections from both editions, friends on Java PCs and those using Bedrock on phones or consoles can build and adventure on the same server.

However, **not every Java Edition server supports Bedrock Edition.** Java and Bedrock use different connection methods, so the server operator needs to provide a way for Bedrock players to connect. Do not decide from the words “Java server” alone; confirm that the official joining guide names support for both editions.

## Java and Bedrock can play together on a compatible server

On a server that supports Java and Bedrock cross-play, players on different editions can join the same server. You do not need to split up just because your friends use different editions.

Game versions, server rules, and installed features can still affect how players join or which controls are available. Start with the joining information kept up to date by the server operator.

## A Java server is not automatically compatible with Bedrock

Java and Bedrock use separate clients and different connection methods. To accept Bedrock players, the server needs a compatible connection route and configuration. For that reason, a server that only publishes a Java address may not accept a direct connection from Bedrock.

When a server says only “Java Edition supported,” do not assume that Bedrock players can join. If someone in your group uses Bedrock, choose a server that explicitly supports both editions or ask the operator before joining.

## Three things to check when choosing a compatible server

### 1. Does the official guide name both editions?

Look for wording such as “Java and Bedrock supported” or “Java/Bedrock cross-play” on the official site or joining guide. If it mentions only Java or only Bedrock, it is safer not to assume that the other edition can join.

### 2. Is there joining guidance for Bedrock?

Check whether the server provides a Bedrock address, port, or connection steps. Even when Java and Bedrock use the same address, Bedrock can require a different port or procedure. If you cannot find guidance, do not decide on your own that it is supported; ask through the official Discord or another official channel.

### 3. Have you checked the latest notices and rules?

Supported editions, recommended versions, and joining requirements can change. Do not rely only on an old introduction: check the latest information on the official site, notices, and Discord. Reading the rules before joining also makes it easier to meet up with friends without trouble.

## What to prepare before playing with friends

- Make sure every player has the connection destination and game version specified for their own edition.
- Read the server rules, age requirements, and first-time joining steps.
- Check the official guide for features that may differ by edition, such as textures, controls, or display.

Doing these three things first helps prevent problems such as only one person being unable to join or players using different connection destinations by mistake.

## Play with Java and Bedrock friends on Aceserver

Aceserver is a free public Minecraft server that players can join from either Java Edition or Bedrock Edition. It is a strong option when you are looking for a server where friends using different editions can play together.

Start with the [Aceserver portal](/en/) to explore world maps and videos, then check the latest joining guidance on the [official Discord](https://discord.gg/acsv). Detailed rules and gameplay information are collected in the [Aceserver WIKI](https://asv-wiki.acecore.net).

## Summary

Java and Bedrock can play together when a server supports connections from both editions. Not every Java Edition server supports Bedrock, so confirm support for both editions, the Bedrock joining method, and the latest rules in the official guide before choosing a server.

Because Aceserver accepts players from both Java and Bedrock, friends using different editions can start playing on the same server.
