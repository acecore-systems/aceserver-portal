There is more than one way to play Minecraft with friends. The right choice changes depending on whether you want to start without a hosting fee, play only while everyone is home, or keep a world available at any time.

This guide starts by choosing Java or Bedrock Edition, then explains how to choose among the free parts of server hosting, a home dedicated server, and Realms. It assumes every player owns a legitimate copy of the game.

## Decide these three things first

### Players' editions and devices

Official dedicated server software is provided separately for Java Edition and Bedrock Edition. Before doing anything else, identify whether everyone uses a PC, phone, or console, and whether they use Java or Bedrock.

### When the world needs to be available

A host world or home PC is usually available only while its host is running. If people need to join while the host is away, plan for an always-on approach and the work required to operate it.

### Who can join

A private world for a few friends needs different safeguards from one open to the public. Public operation includes administrator access, participant management, updates, backups, and rules.

## Choosing a method

| Method                          | Best for                                               | Check first                               |
| ------------------------------- | ------------------------------------------------------ | ----------------------------------------- |
| Multiplayer on the same network | Short sessions at home or nearby                       | Whether the host is running               |
| Dedicated server on a home PC   | A small group that wants to learn setup and management | PC uptime, updates, backups, and exposure |
| Realms                          | Invitation-based play with less management work        | Edition, plan, and invitations            |
| Joining a public server         | Trying a larger shared world first                     | Rules, age guidance, and joining method   |

The phrase free server does not mean that software, hardware, electricity, bandwidth, and maintenance are all free. If you run a server at home, decide who will respond when it stops as well as what it costs.

## Starting a Java Edition dedicated server

Java Edition has official dedicated server software. Its official page explains that it is for Java Edition, that Java must be usable from the command line, and that the setup can be involved.

Use this safer order:

1. Get the server software from the official source.
2. Confirm startup and shutdown in your own environment before exposing it externally.
3. Decide how world data will be backed up.
4. Match the edition and version for a small group, then test joining.
5. Only when external access is needed, carefully configure router and firewall settings, participant management, and administrator permissions.

## Starting a Bedrock Edition dedicated server

Bedrock also has official Dedicated Server Software. The official guidance provides software for Windows or Linux and a bundled usage guide. Do not assume the same devices or joining steps as Java Edition; follow the Bedrock-specific guidance.

For Bedrock, device types, Microsoft account settings, and online settings for child accounts can affect connectivity. Start with a small invited group so problems are easier to diagnose.

## When Realms is a fit

Realms is an option for continuing multiplayer through invited members. Unlike a usual host world that ends when its owner leaves the game, it uses invitations and a subscription arrangement.

It is not free, but it reduces the work of exposing and maintaining a server yourself. Before subscribing, check players' editions, the needed plan, and the official invitation steps.

## Checklist before you open a server

- Back up world data regularly.
- Give administrator access only to people who need it.
- For a public server, prepare participation rules and a way to contact the operator.
- Check compatibility and backups before updating the game or server software.
- Do not share passwords, IP addresses, or administration details unnecessarily.

Use the official [Java Edition server download page](https://www.minecraft.net/en-us/download/server), the [Dedicated Server Software guidance](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-), and the [Bedrock Realms joining guide](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm) for current instructions and downloads.
