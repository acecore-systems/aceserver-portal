When you cannot join a Minecraft server, compare the error message with the server’s guidance. Check the edition, version, and joining requirements first, then narrow down account or connection issues. Check one thing at a time before trying to connect repeatedly.

This article explains what differs between Java Edition, Bedrock Edition, and Switch, where to look for different errors, and which official Aceserver sources to consult. If you want to review the conditions for joining from a Switch or smartphone, see [how to play Minecraft with friends](/en/stories/minecraft-play-with-friends/).

“Multiplayer is disabled” points you toward account permissions, while a timeout is a clue to check the server address, availability, or your connection. The same fix may not work for both. If you are unsure what to enter, check the input screen for your edition in Minecraft’s [official server joining guide](https://www.minecraft.net/en-us/article/how-play-minecraft-server), then work through the checks below.

## First, check: can you connect, or are you having trouble after joining?

- **You cannot connect:** Check the error message, edition, version, joining requirements, account, connection, and whether the server is available.
- **You connected but do not know what to do:** Check the rules, where to go first, and whom to contact if you need help.

A connection problem and uncertainty after joining are different issues. First narrow down why you cannot connect; once you are in, check the server’s guidance.

## Start with these common checks

1. Note the error message, the time you tried to connect, and the device you are using. You can also save a screenshot.
2. Check the server’s official guidance for maintenance, whether new players are currently being accepted, allow-lists, and supported editions.
3. Compare the server address, any required port, and the game version with the guidance, character by character.
4. Restart Minecraft and your device. Check that you are using the normal release, not a test or preview version.
5. If the problem continues, check your account, permissions, and connection one at a time. Changing several settings at once can make the cause harder to identify.

## What to check for Java Edition, Bedrock Edition, and Switch

### Java Edition

Java Edition is available for Windows, macOS, and Linux. If the server is for Java Edition, select the normal release specified in its guidance in the launcher, then enter the server address from the Multiplayer menu. The address is an IP address or hostname, not a web page URL, so enter the address provided by the server.

Pay particular attention to the game version specified by the server and to your mod or launcher settings. If the server is for vanilla Minecraft, unnecessary mods or a test version may prevent you from joining. First try the normal version specified in the server’s guidance, and use additional content only as specified by the server.

### Bedrock Edition

Bedrock Edition is used on Windows, smartphones, and game consoles, among other platforms. Java Edition and Bedrock Edition use different online connection systems. Unless a server says it supports both, you cannot join it using the other edition.

Check that the game is updated, that you are signed in to your Microsoft account, and that multiplayer is allowed. If you are inviting friends to your own world, also check the world’s multiplayer settings. To join a public server, use the address and port that the server provides for Bedrock Edition.

### Nintendo Switch

Minecraft on Nintendo Switch is Bedrock Edition, so Java-only instructions will not work. Online multiplayer in Minecraft requires a signed-in Microsoft account and an active Nintendo Switch Online membership.

Check the game’s update status, the Microsoft account you are signed in to, Nintendo Switch Online, and any parental restrictions on multiplayer, in that order. Server-entry screens and joining methods vary by device, so if you are connecting to a server, follow the method that server provides for Switch. You do not need to try unfamiliar DNS changes or port forwarding just to connect.

## Compare the server’s guidance with what you enter

Check the official guidance for the server you want to join. Do not reuse settings that worked on another server.

| What to check      | Common mismatch                                                                |
| ------------------ | ------------------------------------------------------------------------------ |
| Supported edition  | Using Java Edition instructions in Bedrock Edition, or the reverse             |
| Game version       | Connecting with an old version, snapshot, or preview version                   |
| Address and port   | Using an old notice, entering a typo, or using details for another server      |
| Joining conditions | Missing an allow-list, age requirement, rule acknowledgement, or closed signup |
| Server status      | Repeatedly trying to connect during maintenance, an outage, or a restart       |

Even if a server says that players can join from both Java Edition and Bedrock Edition, the address or joining steps may not be the same. Choose your edition, then follow the instructions for that edition.

## Check your account, permissions, and connection

If you see a message such as “Multiplayer is disabled” or “You do not have permission,” check your account settings as well as the server address. Confirm that you are signed in to the correct Microsoft account, that multiplayer is allowed, and that a child account or family setting is not restricting it.

For a connection error or timeout, restart Minecraft and your device, then check whether your usual internet connection is stable. A school, facility, or workplace network, VPN, or custom DNS may restrict online games.

As a player joining a server, you do not need to open router ports at random. If you have changed custom DNS or port settings, check whether they are affecting Minecraft, and, if needed, restore the previous settings before trying again.

## Choose where to look based on the error

| Message or situation                  | Check first                                                 | Do not do first                                      |
| ------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------- |
| Version mismatch                      | The version specified by the server and your normal release | Switch to a test version or a different edition      |
| Sign-in or authentication error       | The correct Microsoft account and your sign-in status       | Send your password to anyone, including server staff |
| Timeout or unable to connect          | Official outage or maintenance notices and your connection  | Reconnect repeatedly while changing several settings |
| Permission or joining-condition error | Rules, allow-list, age requirements, and invitation status  | Try to bypass the conditions with another account    |

If an error has a name, note that too. When contacting the server team or official support, provide your device, edition, game version, the time you tried to connect, and the error name to help explain what happened.

## Three things to check after joining

1. **Read the rules first:** Building areas, land protection, chat, items, and how to move between worlds vary by server. Check signs at the spawn point, the official site, the WIKI, or pinned Discord messages.
2. **Choose one first goal:** Start with something small, such as looking around the world, gathering resources, or finding a possible base location. A small goal can make it easier to take things in on your first visit.
3. **Save the contact information:** Keep the official help source handy so you can find it if a problem comes up after you connect.

These steps can help both first-time visitors and people returning after a break. Once connected, follow the server’s guidance to get started.

## Where to check if you use Aceserver

This section is about joining Aceserver, not general connection methods. The Aceserver portal says that players can join from either Java Edition or Bedrock Edition. The actual address, port, steps for Switch, server status, and rules may change, so check the following official sources before joining.

1. Check the joining instructions and announcements on the [Aceserver portal](/en/).
2. Check the [official Discord](https://discord.gg/acsv) for maintenance and joining notices.
3. Check the [official WIKI](https://asv-wiki.acecore.net) for in-game rules and guidance for each world.

![A block-style route from a portal to an official guideboard and guidebook for checking Aceserver joining information](/uploads/stories/minecraft-server-cannot-join-official-guidance.webp)

If you still cannot connect, include whether you are using Java Edition or Bedrock Edition, your device (including whether it is a Switch), your game version, the displayed error, and the time you tried. You do not need to share your account password or authentication code.

Game and device screens, as well as online-service conditions, may change. When checking how to use a feature or its requirements, prioritize official guidance from Minecraft and the relevant platform.
