Voici l’annonce du lancement du portail du 7 juin 2026. Pour rejoindre le serveur aujourd’hui, consultez d’abord sa présentation, puis les dernières instructions et règles pour votre édition sur le Discord officiel et le Wiki.

Nous avons mis en ligne le portail officiel d’Aceserver, un serveur Minecraft public et gratuit ouvert à toutes et à tous.

Aceserver accueille les joueurs de Java Edition comme de Bedrock Edition. Le portail réunit en un seul point d’entrée la présentation du serveur, les informations pour participer, les vidéos, les cartes et les liens vers le Wiki.

## Toutes les informations utiles avant de participer au même endroit

Plusieurs informations peuvent être utiles avant de rejoindre Aceserver : de quel type de serveur il s’agit, comment participer, quels mondes sont disponibles et où consulter les règles et les détails. Lorsque ces informations sont dispersées entre Discord, le Wiki, les vidéos et les cartes, une personne qui découvre le serveur peut difficilement savoir par où commencer.

Nous avons donc conçu le portail comme une entrée claire vers les sources existantes, sans chercher à les remplacer.

## Des vidéos, des cartes et un Wiki qui restent reliés

La page d’accueil présente brièvement le serveur et la façon de participer, puis dirige vers les vidéos et les cartes de chaque monde. Les informations qui évoluent, comme les façons de jouer et les règles, restent dans le Wiki ; le portail se concentre sur l’organisation des accès.

## Une structure qui peut continuer à évoluer

Le portail est un site statique construit avec Astro et Tailwind CSS v4. Les textes des pages et les réglages du site peuvent être mis à jour depuis Sveltia CMS, ce qui permet de revoir les annonces et les parcours sans modifier le code.

Les détails de production et d’exploitation figurent dans l’[étude de cas Acecore Systems](https://systems.acecore.net/fr/works/#case-aceserver-portal).

Les informations actuelles pour participer sont disponibles sur la [page d’accueil du portail Aceserver](/fr/).
