Il existe plusieurs façons de jouer à Minecraft avec des amis. Le bon choix dépend de votre souhait de commencer sans payer d'hébergement, de jouer seulement lorsque tout le monde est présent ou de garder un monde accessible à tout moment.

Ce guide commence par le choix entre Java et Bedrock Edition, puis explique comment choisir entre la partie gratuite de l'hébergement, un serveur dédié sur ordinateur domestique et Realms. Il suppose que chaque joueur possède une copie légitime du jeu.

## Décidez d'abord de ces trois points

### Éditions et appareils des joueurs

Le logiciel officiel de serveur dédié est fourni séparément pour Java Edition et Bedrock Edition. Avant de commencer, identifiez si tout le monde utilise un PC, un téléphone ou une console, et s'il utilise Java ou Bedrock.

### Quand le monde doit être disponible

Un monde hébergé ou un ordinateur domestique n'est généralement disponible que tant que l'hôte fonctionne. Si des personnes doivent rejoindre le monde quand l'hôte est absent, prévoyez une solution toujours active et le travail nécessaire pour l'exploiter.

### Qui peut rejoindre

Un monde privé pour quelques amis demande des protections différentes d'un monde ouvert au public. Une exploitation publique comprend les accès d'administration, la gestion des participants, les mises à jour, les sauvegardes et les règles.

## Choisir une méthode

| Méthode                         | Adaptée à                                                     | À vérifier d'abord                                               |
| ------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------- |
| Multijoueur sur le même réseau  | Sessions courtes à la maison ou à proximité                   | Que l'hôte fonctionne                                            |
| Serveur dédié sur PC domestique | Petit groupe voulant apprendre la configuration et la gestion | Temps de fonctionnement, mises à jour, sauvegardes et exposition |
| Realms                          | Jeu sur invitation avec moins de gestion                      | Édition, formule et invitations                                  |
| Rejoindre un serveur public     | Essayer d'abord un grand monde partagé                        | Règles, âge et méthode de participation                          |

L'expression serveur gratuit ne signifie pas que le logiciel, le matériel, l'électricité, la bande passante et la maintenance sont tous gratuits. Si vous l'exécutez chez vous, décidez aussi qui répondra lorsqu'il s'arrêtera.

## Démarrer un serveur dédié Java Edition

Java Edition possède un logiciel officiel de serveur dédié. Sa page officielle indique qu'il est réservé à Java Edition, que Java doit pouvoir être utilisé depuis la ligne de commande et que la configuration peut demander du travail.

Suivez cet ordre plus sûr :

1. Obtenez le logiciel du serveur depuis la source officielle.
2. Confirmez le démarrage et l'arrêt dans votre environnement avant toute exposition externe.
3. Décidez comment les données du monde seront sauvegardées.
4. Alignez l'édition et la version pour un petit groupe, puis testez la connexion.
5. Seulement si un accès externe est nécessaire, configurez avec prudence le routeur et le pare-feu, la gestion des participants et les autorisations d'administration.

## Démarrer un serveur dédié Bedrock Edition

Bedrock possède aussi un Dedicated Server Software officiel. Les indications officielles proposent un logiciel pour Windows ou Linux ainsi qu'un guide d'utilisation inclus. Ne supposez pas que les appareils ou les étapes de participation sont identiques à Java Edition ; suivez les indications propres à Bedrock.

Dans Bedrock, les types d'appareils, les réglages du compte Microsoft et les options en ligne des comptes enfants peuvent affecter la connexion. Commencez avec un petit groupe invité afin de faciliter le diagnostic.

## Quand Realms est adapté

Realms est une solution pour prolonger le multijoueur avec des membres invités. Contrairement à un monde hébergé ordinaire qui s'arrête lorsque son propriétaire quitte le jeu, il utilise des invitations et un abonnement.

Ce n'est pas gratuit, mais cela réduit le travail nécessaire pour exposer et maintenir soi-même un serveur. Avant de vous abonner, vérifiez les éditions des joueurs, la formule nécessaire et les étapes d'invitation officielles.

## Liste avant d'ouvrir un serveur

- Sauvegardez régulièrement les données du monde.
- Donnez l'accès d'administration seulement aux personnes qui en ont besoin.
- Pour un serveur public, préparez des règles de participation et un moyen de joindre la personne qui l'exploite.
- Vérifiez la compatibilité et les sauvegardes avant de mettre à jour le jeu ou le logiciel du serveur.
- Ne partagez pas inutilement mots de passe, adresses IP ou informations d'administration.

Consultez la [page de téléchargement du serveur Java Edition](https://www.minecraft.net/en-us/download/server), les [indications Dedicated Server Software](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-) et le [guide pour rejoindre Realms Bedrock](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm) pour les téléchargements et instructions actuels.
