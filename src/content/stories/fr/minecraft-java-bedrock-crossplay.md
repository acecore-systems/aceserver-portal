Les joueurs Java et Bedrock peuvent jouer ensemble sur un serveur compatible. Si le serveur accepte les connexions des deux éditions, des amis sur Java sur PC et d'autres sur Bedrock sur mobile ou console peuvent construire et partir à l'aventure sur le même serveur.

Cependant, **tous les serveurs Java Edition ne prennent pas en charge Bedrock Edition.** Java et Bedrock utilisent des méthodes de connexion différentes : l'équipe du serveur doit donc prévoir un moyen d'accueillir les joueurs Bedrock. Ne vous fiez pas seulement à la mention « serveur Java » ; vérifiez que le guide officiel indique la prise en charge des deux éditions.

## Java et Bedrock peuvent jouer ensemble sur un serveur compatible

![Un ordinateur portable et un appareil portatif suivent des chemins lumineux vers le même monde serveur en blocs](/uploads/stories/minecraft-java-bedrock-crossplay-devices.webp)

Sur un serveur qui prend en charge le cross-play Java et Bedrock, des joueurs de différentes éditions peuvent rejoindre le même serveur. Il n'est pas nécessaire de séparer votre groupe simplement parce que vos amis utilisent des éditions différentes.

Les versions du jeu, les règles du serveur et les fonctionnalités installées peuvent néanmoins modifier la façon de rejoindre ou les commandes disponibles. Commencez par les informations de participation tenues à jour par l'équipe du serveur.

## Un serveur Java n'est pas automatiquement compatible avec Bedrock

Java et Bedrock utilisent des clients séparés et des méthodes de connexion différentes. Pour accueillir les joueurs Bedrock, le serveur a besoin d'un chemin de connexion et de réglages compatibles. Un serveur qui ne publie qu'une adresse Java peut donc ne pas accepter une connexion directe depuis Bedrock.

Lorsqu'un serveur indique seulement « compatible avec Java Edition », ne supposez pas que les joueurs Bedrock peuvent aussi le rejoindre. Si une personne de votre groupe utilise Bedrock, choisissez un serveur qui annonce explicitement les deux éditions ou demandez à l'équipe avant de rejoindre.

## Trois points pour reconnaître un serveur compatible

![Un aventurier dans un monde de blocs vérifie une carte et des panneaux avant de choisir une entrée compatible](/uploads/stories/minecraft-java-bedrock-crossplay-check.webp)

### 1. Le guide officiel mentionne-t-il les deux éditions ?

Cherchez des mentions telles que « prise en charge de Java et Bedrock » ou « cross-play Java/Bedrock » sur le site officiel ou dans le guide de participation. S'il ne mentionne que Java ou seulement Bedrock, il est plus prudent de ne pas supposer que l'autre édition peut rejoindre.

### 2. Existe-t-il une procédure de participation pour Bedrock ?

Vérifiez que le serveur fournit une adresse, un port ou des étapes de connexion pour Bedrock. Même lorsque Java et Bedrock utilisent la même adresse, Bedrock peut demander un autre port ou une autre procédure. Si vous ne trouvez pas d'indication, ne concluez pas vous-même que le serveur est compatible : demandez sur le Discord officiel ou un autre canal officiel.

### 3. Avez-vous vérifié les annonces et les règles récentes ?

Les éditions prises en charge, les versions recommandées et les conditions de participation peuvent évoluer. Ne vous fiez pas uniquement à une ancienne présentation : consultez les dernières informations du site officiel, des annonces et de Discord. Lire les règles avant de rejoindre aide aussi le groupe à se retrouver sans difficulté.

## À préparer avant de jouer avec des amis

- Vérifiez que chaque joueur utilise la destination de connexion et la version du jeu indiquées pour sa propre édition.
- Lisez les règles du serveur, les conditions d'âge et les étapes de première participation.
- Consultez le guide officiel pour savoir si des fonctions varient selon l'édition, comme les textures, les commandes ou l'affichage.

Ces trois vérifications limitent les problèmes, par exemple lorsqu'une seule personne ne peut pas rejoindre ou lorsque le groupe utilise par erreur des destinations de connexion différentes.

## Jouer avec des amis Java et Bedrock sur Aceserver

![Des amis se retrouvent autour d'une carte dans le hall d'un serveur public construit en blocs](/uploads/stories/minecraft-java-bedrock-crossplay-hub.webp)

Aceserver est un serveur Minecraft public et gratuit que l'on peut rejoindre depuis Java Edition ou Bedrock Edition. C'est une option solide si vous cherchez un serveur où des amis utilisant des éditions différentes peuvent jouer ensemble.

Commencez par le [portail Aceserver](/fr/) pour explorer les cartes des mondes et les vidéos, puis consultez les dernières informations de participation sur le [Discord officiel](https://discord.gg/acsv). Les règles détaillées et les informations de jeu sont réunies dans le [WIKI Aceserver](https://asv-wiki.acecore.net).

## Résumé

Java et Bedrock peuvent jouer ensemble lorsqu'un serveur prend en charge les connexions des deux éditions. Tous les serveurs Java Edition n'acceptent pas Bedrock ; vérifiez donc dans le guide officiel la prise en charge des deux éditions, la méthode de participation Bedrock et les règles récentes avant de choisir un serveur.

Puisqu'Aceserver accepte les joueurs Java et Bedrock, des amis utilisant des éditions différentes peuvent commencer à jouer sur le même serveur.
