Hay más de una forma de jugar Minecraft con amistades. La mejor opción depende de si quieres empezar sin pagar alojamiento, jugar solo mientras todos están en casa o mantener un mundo disponible en cualquier momento.

Esta guía comienza por elegir Java o Bedrock Edition y después explica cómo escoger entre la parte gratuita de alojar un servidor, un servidor dedicado en un ordenador doméstico y Realms. Parte de que cada jugador posee una copia legítima del juego.

## Decide primero estas tres cosas

### Ediciones y dispositivos de los jugadores

El software oficial de servidor dedicado se ofrece por separado para Java Edition y Bedrock Edition. Antes de empezar, identifica si todos usan PC, móvil o consola, y si usan Java o Bedrock.

### Cuándo debe estar disponible el mundo

Un mundo alojado o un ordenador de casa suelen estar disponibles solo mientras el anfitrión está en marcha. Si otras personas deben entrar cuando el anfitrión no está, planifica una opción siempre activa y el trabajo necesario para operarla.

### Quién puede entrar

Un mundo privado para unas pocas amistades necesita medidas distintas que uno abierto al público. Operar uno público incluye accesos de administración, gestión de participantes, actualizaciones, copias de seguridad y reglas.

## Cómo elegir un método

| Método                               | Adecuado para                                                | Comprueba primero                                         |
| ------------------------------------ | ------------------------------------------------------------ | --------------------------------------------------------- |
| Multijugador en la misma red         | Sesiones cortas en casa o cerca                              | Que el anfitrión esté en marcha                           |
| Servidor dedicado en un PC doméstico | Un grupo pequeño que quiere aprender configuración y gestión | Tiempo de actividad, actualizaciones, copias y exposición |
| Realms                               | Juego por invitación con menos trabajo de gestión            | Edición, plan e invitaciones                              |
| Unirse a un servidor público         | Probar primero un mundo compartido grande                    | Reglas, edad y método de acceso                           |

La expresión servidor gratis no significa que software, hardware, electricidad, ancho de banda y mantenimiento no tengan coste. Si lo ejecutas en casa, decide quién responderá cuando se detenga además de cuánto cuesta.

## Empezar un servidor dedicado de Java Edition

Java Edition tiene software oficial de servidor dedicado. Su página oficial explica que es para Java Edition, que Java debe poder usarse desde la línea de comandos y que la configuración puede requerir trabajo.

Sigue este orden más seguro:

1. Obtén el software desde la fuente oficial.
2. Confirma el inicio y la detención en tu entorno antes de exponerlo fuera.
3. Decide cómo se harán las copias de seguridad de los datos del mundo.
4. Iguala la edición y la versión de un grupo pequeño y prueba la conexión.
5. Solo si necesitas acceso externo, configura con cuidado el router y el cortafuegos, la gestión de participantes y los permisos de administración.

## Empezar un servidor dedicado de Bedrock Edition

Bedrock también tiene Dedicated Server Software oficial. La guía oficial ofrece software para Windows o Linux y una guía de uso incluida. No supongas que los dispositivos o los pasos de acceso son iguales que en Java Edition; sigue la guía específica de Bedrock.

En Bedrock, los tipos de dispositivo, la configuración de la cuenta Microsoft y las opciones en línea de cuentas infantiles pueden afectar la conexión. Empieza con un grupo pequeño invitado para que los problemas sean más fáciles de diagnosticar.

## Cuándo conviene Realms

Realms es una opción para mantener el multijugador mediante miembros invitados. A diferencia de un mundo normal alojado que termina cuando su propietario sale del juego, usa invitaciones y una suscripción.

No es gratis, pero reduce el trabajo de exponer y mantener un servidor por tu cuenta. Antes de suscribirte, revisa las ediciones de los jugadores, el plan necesario y los pasos oficiales de invitación.

## Lista antes de abrir un servidor

- Haz copias de seguridad del mundo con regularidad.
- Da acceso de administración solo a quien lo necesite.
- Para un servidor público, prepara reglas de participación y una forma de contactar con la persona operadora.
- Comprueba la compatibilidad y las copias antes de actualizar el juego o el software del servidor.
- No compartas contraseñas, direcciones IP ni datos de administración sin necesidad.

Consulta la [página de descarga del servidor de Java Edition](https://www.minecraft.net/en-us/download/server), la [guía de Dedicated Server Software](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-) y la [guía para unirse a Realms de Bedrock](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm) para obtener instrucciones y descargas actuales.
