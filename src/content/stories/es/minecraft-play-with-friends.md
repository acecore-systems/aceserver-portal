Antes de elegir dónde jugar Minecraft con amigos, confirma que todos pueden usar la misma edición: **Java Edition o Bedrock Edition**. Esta guía compara tu propio mundo, Realms y servidores públicos, y ayuda a elegir una ruta para PC, Switch y móvil.

## Primero: Java y Bedrock no juegan juntos de forma predeterminada

### Java Edition juega con Java Edition

Java Edition es principalmente la edición para PC con Windows, macOS y Linux. Los mundos, Realms y servidores de Java reciben jugadores de Java. Aunque un amigo tenga Minecraft en su PC, un cliente Bedrock no puede entrar en un destino Java de forma predeterminada.

### Bedrock Edition juega con Bedrock Edition

Bedrock Edition se usa en PC con Windows, Switch, teléfonos y consolas. Si el grupo incluye a alguien con Switch o móvil, confirma primero que todos usan Bedrock. Los [requisitos oficiales de multijugador](https://help.minecraft.net/hc/en-us/articles/35930809028749-Requirements-to-Play-Minecraft-Multiplayer-Games) indican que la edición instalada debe coincidir con el destino.

![Un grupo de Java en PC y un grupo de Bedrock con PC, consola portátil y teléfono reunidos en mundos de bloques separados](/uploads/stories/minecraft-play-with-friends-editions.webp)

_El primer paso es que todos usen Java o todos Bedrock; los dos grupos están separados de forma predeterminada._

## Cuatro comprobaciones antes de unirse

1. **Usen la misma edición.** Decidan primero si el grupo jugará Java o Bedrock. No traten la unión entre Java y Bedrock como una condición normal.
2. **Actualicen el juego.** Una diferencia de versión puede impedir que aparezca un mundo o que un jugador entre, incluso dentro de la misma edición.
3. **Comprueben cuentas y requisitos en línea.** Switch, móvil y otras plataformas necesitan iniciar sesión o vincular una cuenta Microsoft para el multijugador. Consulta la [tabla oficial de cuentas y ediciones](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft) para cada dispositivo. El multijugador en línea de consola también necesita la suscripción en línea de la plataforma.
4. **Revisen las cuentas infantiles.** El permiso de multijugador controlado por un adulto puede bloquear invitaciones y entradas. Nunca compartan contraseñas; revisen la privacidad con un padre, madre o tutor.

![Amigos alrededor de un PC, consola portátil y teléfono comprobando el mismo mundo de bloques, la actualización, la cuenta y la seguridad](/uploads/stories/minecraft-play-with-friends-checklist.webp)

_Comprobar juntos edición, actualización, cuenta y ajustes de cuentas infantiles antes de jugar evita muchos problemas al entrar._

## Elegir entre tu mundo, Realms y un servidor público

| Opción           | Mejor para                                             | Estado del anfitrión                                                               | Revisar antes de jugar                                              |
| ---------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Tu propio mundo  | Un grupo pequeño que juega esta noche                  | Los demás entran mientras el dueño mantiene abierto el mundo                       | Misma edición y condiciones de LAN o invitación                     |
| Realms           | Amigos que entran al mismo mundo en distintos horarios | Los invitados pueden entrar con la suscripción activa, incluso si el dueño no está | Realm de Java o Bedrock, invitación y suscripción                   |
| Servidor público | Una comunidad duradera con más jugadores               | El operador administra el mundo                                                    | Edición compatible, método de entrada, reglas, edad y estado actual |

![De izquierda a derecha: un grupo pequeño en su propio mundo, un mundo compartido al que se puede entrar en cualquier momento y una plaza de servidor público con jugadores](/uploads/stories/minecraft-play-with-friends-modes.webp)

_De izquierda a derecha: tu mundo, Realms y un servidor público. Elige según el tamaño del grupo, los horarios y el grado de convivencia con la comunidad que buscas._

### 1. Tu propio mundo: empezar en grupo pequeño

Para amigos en la misma casa o lugar, abrir un mundo por LAN es una primera opción sencilla. En Bedrock, usa dispositivos compatibles en la misma red local y activa el multijugador y la visibilidad LAN en el anfitrión. La [guía oficial de LAN para Bedrock](https://help.minecraft.net/hc/en-us/articles/35697355112717) explica cómo encontrar un mundo tras conectarse a la misma red.

Invitar amigos en línea sigue usando el mundo abierto del anfitrión. Sirve para dos personas que quieren empezar a construir hoy o probar si al grupo le gusta el mismo estilo. Cuando el anfitrión cierra el mundo, los demás no pueden entrar, así que organiza la sesión según su horario.

### 2. Realms: seguir jugando cuando el dueño no está

Realms es el alojamiento oficial de pago de Minecraft. Con la suscripción activa, los amigos invitados pueden entrar aunque el dueño no ejecute el juego. Java Realms y Bedrock Realms son distintos, así que elige el que coincida con el grupo. Consulta la [guía oficial para crear un Realm de Java](https://help.minecraft.net/hc/en-us/articles/4409253767821-How-to-Create-a-Minecraft-Java-Edition-Realm) para Java y la [guía oficial de enlaces de invitación de Realm Bedrock](https://help.minecraft.net/hc/en-us/articles/36974952310925-Manage-Invite-Links-for-Minecraft-Bedrock-Edition-Realms) para Bedrock.

Es adecuado para amigos con horarios distintos de estudios, trabajo o clubes que quieren mejorar una base compartida poco a poco. No publiques un enlace de invitación donde cualquiera pueda verlo; desactívalo o elimínalo cuando deje de ser necesario.

### 3. Servidores públicos: entrar en una comunidad

Un servidor público es un mundo en línea administrado por un operador. Puede ser apropiado para quienes quieren construir, vivir o asistir a eventos con jugadores que todavía no conocen. Antes de entrar, comprueba las reglas, la edición y versión compatibles, las condiciones de edad y el uso de chat de voz o Discord.

Los jugadores de Switch deben leer especialmente la guía del propio servidor sobre dispositivos compatibles y método de entrada. No des por supuesto un método no oficial. Aunque un servidor anuncie soporte para Java y Bedrock, sus requisitos y versiones admitidas dependen de ese servidor.

## Empezar según Java, Bedrock, Switch o móvil

### Jugar Java Edition en un PC

Si todos usan Java Edition, elige un mundo LAN, un Realm de Java o un servidor público de Java. Antes de enviar la invitación, confirma que los amigos iniciaron Java Edition y que las versiones del juego coinciden.

### Jugar Bedrock Edition en un PC

Los jugadores de Windows PC con Bedrock pueden estar en el mismo grupo que jugadores de Switch y móvil con Bedrock. Elige una sesión corta en tu mundo, un Realm continuo o un servidor público según el tiempo y objetivo del grupo.

### Jugar en Nintendo Switch

Minecraft en Switch es Bedrock Edition. Antes del multijugador en línea, comprueba la Nintendo Account, el vínculo con la cuenta Microsoft, Nintendo Switch Online y la actualización del juego. Un grupo con jugador de Switch normalmente debe usar Bedrock y no Java.

### Jugar en teléfono o tableta

Minecraft móvil también es Bedrock Edition. En Android revisa la cuenta Google; en iPhone y iPad, el Apple ID; después inicia sesión o vincula la cuenta Microsoft para multijugador. Probar primero una sesión LAN corta con el Wi-Fi de casa facilita diagnosticar problemas antes de pasar a Realms o a un servidor público.

## Una forma rápida de decidir

- **El grupo incluye Switch o móvil:** usen Bedrock todos.
- **Todos tienen Java Edition en PC:** elijan un mundo, Realm o servidor de Java.
- **Quieren seguir jugando sin el anfitrión:** consideren Realms.
- **Quieren conocer nuevos jugadores:** elijan un servidor público tras leer sus reglas y edición compatible.

Algunos servidores ofrecen su propio sistema adicional de juego cruzado entre Java y Bedrock. No es una promesa predeterminada por el dispositivo, así que confirma el soporte real y actual en la guía oficial del destino.
