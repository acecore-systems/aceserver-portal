和朋友一起玩 Minecraft 的方法不止一种。想不想支付托管费、是否只在大家都在线时玩、世界是否需要随时可进入，都会影响合适的选择。

本指南先帮助你确定 Java 版或基岩版，再说明免费服务器的范围、家用电脑专用服务器和 Realms 的选择思路。这里默认每位玩家都拥有正版游戏。

## 先决定三件事

### 参与者的版本与设备

Java 版和基岩版的官方专用服务器软件是分别提供的。开始前请确认大家使用电脑、手机还是游戏主机，以及使用 Java 版还是基岩版。

### 世界需要在何时可用

主机世界或家用电脑通常只有在主机运行时才能进入。如果需要在主机离开时仍可加入，就要考虑常驻运行方式及其管理工作。

### 谁可以加入

只给几位朋友使用的私密世界，与向公众开放的世界需要的防护不同。公开运行还包括管理员权限、参与者管理、更新、备份和规则。

## 选择方式的参考

| 方法                 | 适合的情况                     | 先确认什么                         |
| -------------------- | ------------------------------ | ---------------------------------- |
| 同一网络内的多人游戏 | 在家中或附近进行短时间游戏     | 主机是否正在运行                   |
| 家用电脑专用服务器   | 想在小团队中学习设置和管理     | 电脑运行时间、更新、备份和公开范围 |
| Realms               | 想以较少管理工作进行邀请制游戏 | 版本、方案和邀请方式               |
| 加入公开服务器       | 想先体验大型共享世界           | 规则、年龄说明和加入方法           |

“免费服务器”不表示软件、硬件、电力、网络和维护都没有成本。在家中运行时，除了费用，也要事先决定服务器停止时由谁处理。

## 开始 Java 版专用服务器

Java 版有官方专用服务器软件。官方页面说明它仅适用于 Java 版，需要能从命令行使用 Java，并且设置过程可能较复杂。

更安全的顺序如下：

1. 从官方来源获取服务器软件。
2. 在对外开放前，先在自己的环境中确认启动和停止。
3. 决定世界数据的备份方法。
4. 让少量玩家的版本保持一致后测试连接。
5. 仅在需要外部访问时，再谨慎设置路由器和防火墙、参与者管理及管理员权限。

## 开始基岩版专用服务器

基岩版也有官方 Dedicated Server Software。官方说明提供 Windows 或 Linux 版软件及随附使用指南。不要假设设备或加入步骤与 Java 版相同，请遵循基岩版专用说明。

在基岩版中，设备类型、Microsoft 账户设置和儿童账户的在线设置都可能影响连接。先让少量受邀玩家测试，更容易排查问题。

## 适合使用 Realms 的情况

Realms 适合希望通过邀请成员持续多人游戏的玩家。与所有者离开游戏后就结束的普通主机世界不同，它通过邀请和订阅机制运行。

它并非免费，但可减少自行公开和维护服务器的工作。订阅前请通过官方帮助确认玩家版本、所需方案和邀请步骤。

## 开放服务器前的检查清单

- 定期备份世界数据。
- 只向确有需要的人授予管理员权限。
- 面向公众开放时，准备参与规则和联系运营者的方式。
- 更新游戏或服务器软件前，确认兼容性并完成备份。
- 不要不必要地分享密码、IP 地址或管理信息。

请从官方 [Java 版服务器下载页面](https://www.minecraft.net/en-us/download/server)、[Dedicated Server Software 说明](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-) 和 [基岩版 Realms 加入指南](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm)确认当前的下载和操作步骤。
