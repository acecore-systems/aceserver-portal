搜索“推荐的 Minecraft 服务器”时，排行榜或简短介绍似乎已经足够。不过，能否长期玩得开心，取决于你想玩的方式、加入流程是否清楚，以及自己是否认同服务器的规则和氛围。

本文由 Aceserver 官方 Portal 面向正在寻找公开服务器的玩家发布。我们不会制作特定的排行榜，而是介绍选择服务器时应确认的要点，以及 Aceserver 可能适合哪些玩家。

## 为什么不能只看排行榜

“人多”或“有名”可以帮助你缩小最初的候选范围。不过，如果所用版本或想玩的方式不合适，可能很难持续游玩。加入前请确认以下六点。

1. **支持的版本**：确认你使用 Java 版还是基岩版，以及能否和朋友加入同一台服务器。
2. **玩法方向**：看看服务器的方向是否符合你喜欢的建筑、冒险、经济或小游戏等玩法。
3. **加入步骤是否清楚**：如果加入步骤、所需设置和最先要阅读的说明都整理好了，第一次加入也会更轻松。
4. **规则和社区**：能在加入前通过[官方 WIKI](https://asv-wiki.acecore.net)确认禁止事项和社区重视的内容，会更安心。
5. **能否找到想了解的信息**：看看是否容易找到世界、活动和玩法等感兴趣信息的入口。
6. **是否容易迈出第一步**：知道咨询渠道和说明入口，可以减轻加入前的不安。

## Aceserver 可能适合哪些玩家

Aceserver 是一台 Java 版和基岩版玩家都可以加入、任何人都可参加的免费公开 Minecraft 服务器。它可能适合想体验接近原版且高度自由玩法的玩家，也适合想先通过 Discord 确认说明后再加入的玩家。

本页是官方 Portal 的说明。我们不会把 Aceserver 与其他服务器比较优劣，请根据以上要点和自己的玩法偏好来选择。

## 加入的三个步骤

1. [在 Portal 确认服务器概要](/zh-cn/)
2. [加入官方 Discord](https://discord.gg/acsv)
3. [在 WIKI 阅读规则和加入前需要确认的信息](https://asv-wiki.acecore.net)

加入条件和规则可能会更新，实际加入前请确认官方 Discord 和 WIKI 的最新说明。

## 如果还在犹豫，先看加入说明

判断是否适合自己的可靠方式，是查看实际说明和社区入口。确认自己使用 Java 版还是基岩版后，请先[查看 Aceserver 的加入说明](/zh-cn/)。
