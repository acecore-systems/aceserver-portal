Java 版和基岩版玩家可以在兼容的服务器中一起游玩。只要服务器接受两个版本的连接，使用 Java 版电脑的朋友与使用手机或游戏机基岩版的朋友，就能在同一服务器建造和冒险。

不过，**并非所有 Java 版服务器都支持基岩版。** Java 版和基岩版的连接方式不同，服务器运营方需要准备让基岩版玩家接入的机制。不要只因为写着“Java 版服务器”就下结论；请在官方加入说明中确认是否明确支持两个版本。

## Java 版和基岩版可在兼容服务器中一起游玩

支持 Java 版与基岩版跨平台游玩的服务器，允许不同版本的玩家加入同一服务器。朋友所用版本不同，并不意味着必须分开游玩。

不过，游戏版本、服务器规则和已安装功能仍可能影响加入方式或可用操作。应先查看由服务器运营方持续更新的加入说明。

## Java 版服务器并不一定兼容基岩版

Java 版和基岩版使用不同客户端，连接方式也不同。要接纳基岩版玩家，服务器需要兼容的连接路径和设置。因此，只有 Java 版地址说明的服务器，不一定能让基岩版直接连接。

如果服务器只写“支持 Java 版”，不要推定基岩版也能加入。队伍中有人使用基岩版时，请选择明确说明支持两个版本的服务器，或在加入前向运营方确认。

## 识别兼容服务器的三个确认点

### 1. 官方说明是否写明两个版本？

请在官方网站或加入指南中寻找“支持 Java 版和基岩版”或“Java/Bedrock 跨平台游玩”等表述。如果只写了 Java 版或基岩版，最好不要假定另一个版本也能加入。

### 2. 是否提供基岩版的加入说明？

确认是否提供了基岩版的地址、端口或连接步骤。即使两个版本使用同一个地址，基岩版也可能需要不同的端口或步骤。如果找不到说明，不要自行判断为已支持；请通过官方 Discord 或其他官方渠道确认。

### 3. 是否查看了最新公告和规则？

支持的版本、推荐版本和加入条件可能会更新。不要只依赖旧介绍；还要查看官方网站、公告和 Discord 的最新信息。加入前阅读规则，也能让大家会合后更顺利地游玩。

## 和朋友游玩前需要准备的事

- 确认每位玩家都使用自己版本对应的连接地址和游戏版本。
- 阅读服务器规则、年龄条件和首次加入步骤。
- 通过官方说明确认纹理、操作或显示等功能是否会因版本不同而有差异。

先确认这三点，可以减少“只有一人无法进入”或“以为是同一服务器却使用了不同连接地址”等问题。

只要服务器支持两个版本的连接，Java 版和基岩版就能一起游玩。但并非所有 Java 版服务器都支持基岩版，因此选择前应在官方说明中确认两个版本的支持情况、基岩版加入方法和最新规则。
