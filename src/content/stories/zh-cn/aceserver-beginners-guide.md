第一次来到 Aceserver 时，信息很多，可能不知道应该先看什么。本指南会按顺序介绍官方 Portal、世界地图、视频、WIKI 和连接问题的使用方法。

如果不知道在哪里查找说明，可以在 Portal 的站内搜索中输入“参加方法”或“世界地图”等关键词。打开搜索到的页面，确认最新的参加条件和规则。

连接地址、端口、包括 Switch 在内的设备步骤、参加条件和规则都有可能更新。本文只是入口说明；实际加入前，请始终以最新的官方说明为准。

## 首先打开的四个官方页面

1. 在 [Aceserver 官方 Portal](/zh-cn/) 查看总入口和公告。
2. 加入[官方 Discord](https://discord.gg/acsv)，查看最新的参加与维护通知。
3. 在 [Aceserver WIKI 的参加方法](https://asv-wiki.acecore.net/article/in/)确认当前加入步骤。
4. 进入游戏前阅读 [Aceserver WIKI 的规则与封禁条件](https://asv-wiki.acecore.net/article/rule/)。

按照这个顺序，可以找到适用于当前 Aceserver 的信息，而不是依赖过时文章或非官方连接方法。如果有不清楚的地方，请不要猜测，直接通过官方 Discord 询问。

![按顺序经过 Portal、官方 Discord、WIKI 参加指南和 WIKI 规则的方块风格新手导览图](/uploads/stories/aceserver-beginners-guide-official-route.png)

## 用 Portal 找到下一步该去哪里

Portal 是第一次认识 Aceserver 时的指示牌。它汇总了 Java 版和基岩版都能参加的信息，以及官方 Discord、WIKI、世界地图和视频的入口。

想了解 Java 版与基岩版一起游玩的条件，以及如何识别支持两种版本的服务器，请参阅[Java 版和基岩版可以一起玩吗？](/zh-cn/stories/minecraft-java-bedrock-crossplay/)。

先从首页了解整体内容，再根据目的打开对应页面。

| 想做什么           | 打开哪里     | 先确认什么                   |
| ------------------ | ------------ | ---------------------------- |
| 了解最新参加信息   | 官方 Discord | 维护、参加条件与连接公告     |
| 看看有哪些地点     | 世界地图     | 想看的世界和地图公开状态     |
| 了解社区或活动氛围 | 视频         | 官方频道的最新视频和公开会议 |
| 查询规则或玩法     | WIKI         | 参加方法、规则和各世界说明   |

Portal 是最新信息的入口，并不是记住连接细节的地方。连接前请再次查看参加方法和 Discord 公告。

## 用世界地图寻找想去的地方

[世界地图](/zh-cn/world-map/)提供主世界、资源世界、RPG、大厅、Season 系列和活动地图等公开地图的入口。想参观建筑、收集资源或游玩 RPG 时，先从地图知道世界名称，更容易在 WIKI 或 Discord 中找到相关说明。

地图正在显示，并不代表现在一定可以进入，或一定可以使用某项功能。世界状态和移动方式可能变化，行动前请确认最新公告和规则。

## 用视频了解服务器的氛围

[官方视频页面](/zh-cn/youtube-search-aceserver/)会显示活动直播、世界介绍和公开会议等最新视频。当你想了解文字难以表达的建筑、活动和社区氛围时很有帮助。

视频是认识社区的入口。不要把旧视频中的连接地址、功能或规则当作当前内容；参加方法和规则请以官方 Discord 和 WIKI 当前页面为准。

## 用 WIKI 确认参加方法和规则

[Aceserver WIKI 的参加方法](https://asv-wiki.acecore.net/article/in/)是参加步骤的依据，[Aceserver WIKI 的规则与封禁条件](https://asv-wiki.acecore.net/article/rule/)是行为标准的依据。第一次参加前，请确认这些内容与你想进行的玩法是否有关。

- 尊重其他参加者、他们的建筑、作物、动物和个人信息。
- 进入其他人的建筑或领地前先取得所有者许可。
- 不使用会给服务器造成负担的装置、被禁止的客户端或作弊工具。
- 大型建筑、整地、挖掘和装置可能需要确认或申请。
- 不确定时不要自行判断，应向工作人员询问。

这不是详细规则的替代品。条件和适用范围可能变动，请阅读 WIKI 原文以确认准确数值和禁止事项。

## 第一次参加请按这个顺序进行

1. 在官方 Portal 确认 Java 版与基岩版支持，并找到各官方入口。
2. 加入官方 Discord，在连接前查看最新公告。
3. 阅读 WIKI 的参加方法和规则。
4. 只使用为自己版本和设备正式说明的连接方式。
5. 进入后先阅读附近的说明，再设定一个小目标。

不要只根据旧截图或视频决定地址、端口、DNS 修改或 Switch 步骤。不要强行尝试非官方绕过方法；官方信息不清楚时请先询问。

如果想先整理 Java 版、基岩版、Switch 和手机的多人游戏选择，可以参考[如何与朋友一起玩 Minecraft](/zh-cn/stories/minecraft-play-with-friends/)。实际参加 Aceserver 时，应优先遵循本文所示的官方 Discord 和 WIKI。

## 将通用连接问题与 Aceserver 说明分开确认

无法加入可能由游戏版本、版本号、Microsoft 帐户、网络或服务器当前说明等多种原因造成。请先阅读[无法加入 Minecraft 服务器时的检查方法](/zh-cn/stories/minecraft-server-cannot-join/)，进行适用于各种设备的基本排查。

之后再确认 Aceserver 的官方 Discord 和 WIKI 最新说明。连接地址、端口、Switch 加入步骤、维护和参加条件必须以官方说明为准，而不是通用文章。

![依次确认游戏版本类型、客户端版本、帐户和网络后再查看官方说明的方块风格连接检查图](/uploads/stories/aceserver-beginners-guide-connection-check.png)

咨询时，准备以下信息会更容易说明情况：

- 使用 Java 版还是基岩版，以及所用设备
- Minecraft 的版本
- 显示的错误和尝试连接的时间
- 已经确认过的内容

不需要分享密码、认证码或帐户个人信息。

## 享受最初的一小时

进入后不必马上开始大型建筑或装置制作。阅读出生点附近的说明，从世界地图选择感兴趣的地方，在 WIKI 确认所需规则，然后设定一个小目标。

例如参观城镇、收集一点资源、寻找基地候选地点，或在地图上寻找视频里看到的地方。收藏官方 Portal、Discord 和 WIKI，遇到问题时就能回到可靠信息。

游玩前后，也可以通过[阿尔法君的绘画日记](/zh-cn/stories/alpha-diary-guide/)阅读不同日期的记录。自己选择感兴趣的日期，按照自己的节奏探索。

## 总结

第一次来到 Aceserver 时，先从官方 Portal 开始，在官方 Discord 查看最新信息，再阅读 WIKI 的参加方法和规则后进入游戏。世界地图和视频可以帮助你找到想探索的地方，并了解服务器的氛围。

连接信息和规则可能变化。请优先使用当前官方 Discord 和 WIKI 的说明，安全地开始你的第一步。
