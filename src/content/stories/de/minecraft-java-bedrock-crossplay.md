Java- und Bedrock-Spieler können auf einem kompatiblen Server zusammen spielen. Wenn der Server Verbindungen von beiden Editionen akzeptiert, können Freunde mit Java auf dem PC und mit Bedrock auf Mobilgeräten oder Konsolen auf demselben Server bauen und Abenteuer erleben.

Allerdings **unterstützt nicht jeder Java-Edition-Server Bedrock Edition.** Java und Bedrock verwenden unterschiedliche Verbindungsmethoden; das Serverteam muss daher einen Weg für Bedrock-Spieler bereitstellen. Entscheide nicht allein anhand der Bezeichnung „Java-Server“, sondern prüfe in der offiziellen Beitrittsanleitung, ob beide Editionen genannt werden.

## Java und Bedrock können auf kompatiblen Servern zusammen spielen

![Ein Laptop und ein Handgerät folgen leuchtenden Wegen in dieselbe Blockserverwelt](/uploads/stories/minecraft-java-bedrock-crossplay-devices.webp)

Auf einem Server mit Java- und Bedrock-Crossplay können Spieler verschiedener Editionen demselben Server beitreten. Ihr müsst euch nicht nur deshalb aufteilen, weil eure Freunde unterschiedliche Editionen verwenden.

Spielversionen, Serverregeln und installierte Funktionen können dennoch beeinflussen, wie man beitritt oder welche Steuerung verfügbar ist. Beginne mit den Beitrittsinformationen, die das Serverteam aktuell hält.

## Ein Java-Server ist nicht automatisch mit Bedrock kompatibel

Java und Bedrock verwenden getrennte Clients und unterschiedliche Verbindungsmethoden. Um Bedrock-Spieler aufzunehmen, benötigt ein Server einen kompatiblen Verbindungsweg und passende Einstellungen. Deshalb akzeptiert ein Server, der nur eine Java-Adresse veröffentlicht, möglicherweise keine direkte Verbindung aus Bedrock.

Wenn bei einem Server nur „Java Edition unterstützt“ steht, solltest du nicht davon ausgehen, dass auch Bedrock-Spieler beitreten können. Nutzt jemand in eurer Gruppe Bedrock, wählt einen Server mit ausdrücklich angekündigter Unterstützung beider Editionen oder fragt das Team vor dem Beitritt.

## Drei Punkte zum Erkennen eines kompatiblen Servers

![Eine Figur in einer Blockwelt prüft Karte und Wegweiser, bevor sie einen kompatiblen Eingang wählt](/uploads/stories/minecraft-java-bedrock-crossplay-check.webp)

### 1. Nennt die offizielle Anleitung beide Editionen?

Suche auf der offiziellen Website oder in der Beitrittsanleitung nach Formulierungen wie „Java und Bedrock unterstützt“ oder „Java/Bedrock-Crossplay“. Wenn nur Java oder nur Bedrock erwähnt wird, ist es sicherer, nicht davon auszugehen, dass die andere Edition beitreten kann.

### 2. Gibt es Beitrittsinformationen für Bedrock?

Prüfe, ob der Server für Bedrock eine Adresse, einen Port oder Verbindungsschritte angibt. Selbst wenn Java und Bedrock dieselbe Adresse verwenden, kann Bedrock einen anderen Port oder Ablauf benötigen. Falls du keine Anleitung findest, entscheide nicht selbst, dass der Server unterstützt wird, sondern frage über den offiziellen Discord oder einen anderen offiziellen Kanal nach.

### 3. Hast du die neuesten Hinweise und Regeln geprüft?

Unterstützte Editionen, empfohlene Versionen und Beitrittsbedingungen können sich ändern. Verlasse dich nicht nur auf eine alte Vorstellung, sondern prüfe die aktuellen Informationen auf der offiziellen Website, in den Hinweisen und auf Discord. Wenn ihr die Regeln vor dem Beitritt lest, könnt ihr euch anschließend leichter ohne Probleme treffen.

## Was ihr vor dem Spielen mit Freunden vorbereiten solltet

- Stellt sicher, dass jeder Spieler das für seine Edition angegebene Verbindungsziel und die richtige Spielversion hat.
- Lest die Serverregeln, Altersbedingungen und Schritte für den ersten Beitritt.
- Prüft in der offiziellen Anleitung, ob sich Funktionen wie Texturen, Steuerung oder Darstellung je nach Edition unterscheiden.

Diese drei Prüfungen helfen, Probleme zu vermeiden, etwa dass nur eine Person nicht beitreten kann oder dass versehentlich unterschiedliche Verbindungsziele verwendet werden.

## Mit Java- und Bedrock-Freunden auf Aceserver spielen

![Freunde treffen sich an einer Karte in der Lobby eines öffentlichen Blockservers](/uploads/stories/minecraft-java-bedrock-crossplay-hub.webp)

Aceserver ist ein kostenloser öffentlicher Minecraft-Server, dem man sowohl mit Java Edition als auch mit Bedrock Edition beitreten kann. Er ist eine gute Option, wenn du einen Server suchst, auf dem Freunde mit unterschiedlichen Editionen zusammen spielen können.

Sieh dir zuerst im [Aceserver-Portal](/de/) Weltkarten und Videos an und prüfe dann die aktuellen Beitrittsinformationen im [offiziellen Discord](https://discord.gg/acsv). Detaillierte Regeln und Spielinformationen findest du im [Aceserver-WIKI](https://asv-wiki.acecore.net).

## Zusammenfassung

Java und Bedrock können zusammen spielen, wenn ein Server Verbindungen beider Editionen unterstützt. Nicht jeder Java-Edition-Server akzeptiert Bedrock. Prüfe daher vor der Wahl eines Servers in der offiziellen Anleitung die Unterstützung beider Editionen, die Bedrock-Beitrittsmethode und die neuesten Regeln.

Da Aceserver Java- und Bedrock-Spieler akzeptiert, können Freunde mit unterschiedlichen Editionen auf demselben Server losspielen.
