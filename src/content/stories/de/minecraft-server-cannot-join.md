Wenn Sie keinem Minecraft-Server beitreten können, gleichen Sie die Fehlermeldung mit den Serverhinweisen ab. Prüfen Sie danach Edition, Version und Beitrittsbedingungen und grenzen Sie mögliche Probleme mit Konto und Netzwerk ein. Versuchen Sie nicht wiederholt, eine Verbindung herzustellen, sondern prüfen Sie die Punkte einzeln.

Dieser Artikel erklärt, worauf es bei Java Edition, Bedrock Edition und Nintendo Switch ankommt, welche Prüfschritte zu verschiedenen Fehlermeldungen passen und wo Sie offizielle Aceserver-Hinweise finden. Wenn Sie zunächst die Bedingungen für den Beitritt mit Switch oder Smartphone einordnen möchten, lesen Sie auch [Minecraft mit Freunden spielen](/de/stories/minecraft-play-with-friends/).

„Mehrspieler ist deaktiviert“ ist ein Hinweis auf Kontoberechtigungen; bei einer Zeitüberschreitung sollten Sie Serveradresse, Verfügbarkeit und Verbindung prüfen. Dieselbe Maßnahme hilft nicht in jedem Fall. Wenn Sie nicht wissen, wo Sie Angaben machen müssen, sehen Sie sich den Eingabebildschirm für Ihre Edition in der [offiziellen Anleitung zum Beitreten zu einem Server](https://www.minecraft.net/en-us/article/how-play-minecraft-server) an. Gehen Sie dann die folgenden Punkte der Reihe nach durch.

## Zuerst klären: Ist die Verbindung unmöglich oder gibt es nach dem Beitritt ein Problem?

- **Keine Verbindung zum Server:** Prüfen Sie die Fehlermeldung, Edition, Version, Beitrittsbedingungen, Konto, Netzwerk und den Serverstatus.
- **Sie sind verbunden, wissen aber nicht, was Sie tun sollen:** Informieren Sie sich über Regeln, den ersten Anlaufpunkt und die Kontaktstelle bei Problemen.

Ein Verbindungsproblem und Unsicherheit nach dem Beitritt sind zwei verschiedene Dinge. Grenzen Sie zuerst die Verbindungsursache ein und lesen Sie nach dem Beitritt die Hinweise des Servers.

## Gemeinsame erste Prüfungen

1. Notieren Sie die Fehlermeldung, den Zeitpunkt des Verbindungsversuchs und das verwendete Gerät. Sie können auch einen Screenshot aufnehmen.
2. Prüfen Sie in den offiziellen Serverhinweisen, ob Wartungsarbeiten laufen, die Aufnahme pausiert ist, eine Whitelist gilt oder bestimmte Editionen unterstützt werden.
3. Vergleichen Sie Serveradresse, erforderlichen Port und Spielversion Zeichen für Zeichen mit den Angaben des Servers.
4. Starten Sie Minecraft und das Gerät neu. Prüfen Sie, ob Sie die normale Version und nicht eine Test- oder Preview-Version verwenden.
5. Wenn das Problem weiterhin besteht, prüfen Sie Konto, Berechtigungen und Netzwerk einzeln. Wenn Sie mehrere Einstellungen gleichzeitig ändern, wird es schwieriger, die Ursache zu finden.

## Was Sie bei Java, Bedrock und Switch prüfen sollten

### Java Edition

Java Edition ist für Windows, macOS und Linux verfügbar. Wenn der Server für Java Edition vorgesehen ist, wählen Sie im Launcher die angegebene reguläre Version und geben Sie die Serveradresse unter „Mehrspieler“ ein. Als Adresse dienen eine IP-Adresse oder ein Hostname. Das ist nicht dasselbe wie die URL einer Webseite; verwenden Sie die vom Server angegebene Adresse.

Prüfen Sie insbesondere die vom Server verlangte Spielversion sowie die Einstellungen für MODs und Launcher. Wenn ein Server für Vanilla vorgesehen ist, kann der Beitritt mit unnötigen MODs oder einer Testversion scheitern. Probieren Sie zuerst die in den Serverhinweisen genannte reguläre Version aus und verwenden Sie zusätzliche Inhalte nur, wenn der Server sie ausdrücklich angibt.

### Bedrock Edition

Bedrock Edition wird unter anderem auf Windows, Smartphones und Spielkonsolen verwendet. Java und Bedrock nutzen unterschiedliche Online-Verbindungsverfahren. Wenn ein Server nicht ausdrücklich beide Editionen unterstützt, können Sie ihm nicht mit der jeweils anderen Edition beitreten.

Prüfen Sie, ob das Spiel aktualisiert ist, Sie mit Ihrem Microsoft-Konto angemeldet sind und der Mehrspieler freigegeben ist. Wenn Sie Freunde in Ihre eigene Welt einladen, prüfen Sie auch dort die Mehrspieler-Einstellung. Verwenden Sie für einen öffentlichen Server die Adresse und den Port, die der Server für Bedrock angibt.

### Nintendo Switch

Minecraft für Nintendo Switch ist eine Bedrock-Version. Hinweise, die ausschließlich für Java Edition gelten, helfen daher nicht beim Beitritt. Für den Online-Mehrspieler von Minecraft sind die Anmeldung mit einem Microsoft-Konto und eine gültige Nintendo-Switch-Online-Mitgliedschaft erforderlich.

Prüfen Sie nacheinander, ob das Spiel aktualisiert ist, welches Microsoft-Konto angemeldet ist, ob Nintendo Switch Online aktiv ist und ob eine elterliche Beschränkung den Mehrspieler verhindert. Der Bildschirm zum Hinzufügen eines Servers und die Beitrittsmethode unterscheiden sich je nach Gerät. Verwenden Sie für einen beliebigen Server deshalb die Anleitung, die dieser für Switch bereitstellt. Sie müssen nicht auf Verdacht DNS-Einstellungen ändern oder Ports freigeben.

## Serverhinweise und eingegebene Angaben abgleichen

Prüfen Sie die offiziellen Hinweise des Servers, dem Sie beitreten möchten. Übernehmen Sie keine Einstellungen, die bei einem anderen Server funktioniert haben.

| Zu prüfender Punkt   | Häufige Abweichung                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| Unterstützte Edition | Java-Hinweise mit Bedrock verwenden oder umgekehrt                                                   |
| Spielversion         | Mit einer alten Version, einem Snapshot oder einer Preview-Version verbinden                         |
| Adresse und Port     | Eine alte Mitteilung, eine falsch eingegebene Adresse oder Angaben zu einem anderen Server verwenden |
| Beitrittsbedingungen | Whitelist, Altersvorgaben, Regelbestätigung oder Aufnahmestopp übersehen                             |
| Serverstatus         | Während Wartung, Störung oder Neustart wiederholt versuchen, eine Verbindung herzustellen            |

Auch wenn ein Server angibt, dass der Beitritt sowohl mit Java als auch mit Bedrock möglich ist, müssen Adresse und Vorgehen nicht gleich sein. Entscheiden Sie zuerst, welche Edition Sie verwenden, und folgen Sie den Hinweisen für genau diese Edition.

## Konto, Berechtigungen und Netzwerk prüfen

Wenn die Meldung „Mehrspieler ist deaktiviert“ oder „Keine Berechtigung“ erscheint, prüfen Sie neben der Serveradresse auch die Kontoeinstellungen. Stellen Sie fest, ob Sie beim richtigen Microsoft-Konto angemeldet sind, der Mehrspieler freigegeben ist und für ein Kinder- oder Familienkonto Einschränkungen gelten.

Bei einem Netzwerkfehler oder einer Zeitüberschreitung starten Sie Minecraft und das Gerät neu und prüfen Sie, ob Ihre übliche Internetverbindung stabil ist. In Schul-, Einrichtungs- oder Unternehmensnetzwerken sowie bei VPNs oder eigenen DNS-Einstellungen kann der Zugang zu Online-Spielen eingeschränkt sein.

Als beitretende Person müssen Sie nicht auf Verdacht Router-Ports freigeben. Wenn Sie eigene DNS- oder Porteinstellungen geändert haben, prüfen Sie, ob sie die Minecraft-Verbindung beeinflussen. Setzen Sie die Einstellungen bei Bedarf auf den vorherigen Stand zurück und versuchen Sie es erneut.

## Anhand der Fehlermeldung den nächsten Prüfschritt wählen

| Meldung oder Situation                              | Zuerst prüfen                                                              | Nicht zuerst tun                                                     |
| --------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Abweichende Version                                 | Die vom Server verlangte Version und die reguläre Version, die Sie starten | Zu einer Testversion oder einer anderen Edition wechseln             |
| Anmelde- oder Authentifizierungsfehler              | Das richtige Microsoft-Konto und den Anmeldestatus                         | Das Passwort an andere Personen oder das Serverteam senden           |
| Zeitüberschreitung oder keine Verbindung            | Offizielle Hinweise zu Störungen oder Wartung und die eigene Verbindung    | Immer wieder verbinden und gleichzeitig mehrere Einstellungen ändern |
| Fehler bei Berechtigungen oder Beitrittsbedingungen | Regeln, Whitelist, Altersvorgaben und Einladungsstatus                     | Versuchen, die Bedingungen mit einem anderen Konto zu umgehen        |

Wenn ein Fehlername angezeigt wird, notieren Sie ihn ebenfalls. Wenn Sie das Serverteam oder den offiziellen Support kontaktieren, können Sie Ihre Situation mit Gerät, Edition, Spielversion, Zeitpunkt des Verbindungsversuchs und Fehlername leichter beschreiben.

## Drei Dinge, die Sie nach dem Beitritt prüfen sollten

1. **Lesen Sie zuerst die Regeln:** Baugebiete, Landschutz, Chat, Gegenstände und der Wechsel zwischen Welten sind von Server zu Server unterschiedlich. Prüfen Sie die Schilder am Spawn, die offizielle Website, das WIKI oder angeheftete Discord-Nachrichten.
2. **Setzen Sie sich ein erstes kleines Ziel:** Sehen Sie sich die Welt an, sammeln Sie Ressourcen oder suchen Sie einen möglichen Standort für Ihre Basis. Ein kleines Ziel hilft, die Informationen beim ersten Besuch zu ordnen.
3. **Speichern Sie die Kontaktstelle für Probleme:** So finden Sie bei Schwierigkeiten nach dem Beitritt die offiziellen Hinweise wieder.

Diese drei Schritte sind sowohl für neue als auch für zurückkehrende Spielende hilfreich. Folgen Sie nach dem Beitritt den Hinweisen des Servers und beginnen Sie dann zu spielen.

## Anlaufstellen für Aceserver

Dieser Abschnitt enthält Hinweise zum Beitritt zu Aceserver und ist keine allgemeine Anleitung für andere Server. Im offiziellen Aceserver-Portal wird erklärt, dass sowohl Spielerinnen und Spieler mit Java als auch mit Bedrock beitreten können. Die tatsächlichen Verbindungsziele, Ports, Schritte für Switch, der Serverstatus und die Regeln können sich ändern. Prüfen Sie daher vor dem Beitritt die folgenden offiziellen Hinweise.

1. Prüfen Sie im [Aceserver-Portal](/de/) den Zugang zum Beitritt und die Mitteilungen.
2. Informieren Sie sich im [offiziellen Discord](https://discord.gg/acsv) über Hinweise zu Wartungsarbeiten und zum Beitritt.
3. Lesen Sie im [offiziellen WIKI](https://asv-wiki.acecore.net) die Regeln im Spiel und die Hinweise zu den einzelnen Welten.

![Ein Weg im Blockstil führt über das Portal und eine offizielle Hinweistafel zu einem Handbuch mit Informationen zum Beitritt](/uploads/stories/minecraft-server-cannot-join-official-guidance.webp)

Wenn Sie weiterhin keine Verbindung herstellen können, geben Sie an, ob Sie Java oder Bedrock verwenden, welches Gerät Sie nutzen (bei Switch auch dies nennen), welche Spielversion installiert ist, welche Fehlermeldung erscheint und wann Sie den Verbindungsversuch unternommen haben. Sie müssen weder Ihr Kontopasswort noch einen Authentifizierungscode weitergeben.

## Für die Fehlersuche offizielle Informationen bevorzugen

Bildschirme im Spiel, Einstellungen der Geräte und Bedingungen für Onlinedienste können sich ändern. Wenn Sie Bedienungsabläufe oder Nutzungsbedingungen prüfen, verwenden Sie vorrangig die offiziellen Hinweise von Minecraft und der jeweiligen Plattform.
