Es gibt mehr als eine Möglichkeit, Minecraft mit Freunden zu spielen. Die passende Wahl hängt davon ab, ob du ohne Hostinggebühr starten, nur spielen möchtest, wenn alle zu Hause sind, oder eine Welt jederzeit verfügbar halten willst.

Dieser Leitfaden beginnt mit der Wahl zwischen Java und Bedrock Edition und erklärt dann, wie du zwischen dem kostenlosen Teil des Serverbetriebs, einem Dedicated Server auf einem Heim-PC und Realms wählst. Er setzt voraus, dass jeder Spieler eine rechtmäßige Kopie des Spiels besitzt.

## Entscheide zuerst diese drei Dinge

### Editionen und Geräte der Spieler

Offizielle Dedicated-Server-Software wird getrennt für Java Edition und Bedrock Edition angeboten. Kläre vor dem Start, ob alle PC, Mobilgerät oder Konsole nutzen und ob sie Java oder Bedrock spielen.

### Wann die Welt verfügbar sein muss

Eine Host-Welt oder ein Heim-PC ist gewöhnlich nur verfügbar, solange der Host läuft. Wenn andere auch beitreten sollen, wenn der Host nicht da ist, brauchst du eine dauerhaft laufende Lösung und musst ihren Betriebsaufwand einplanen.

### Wer beitreten darf

Eine private Welt für wenige Freunde braucht andere Schutzmaßnahmen als eine öffentliche Welt. Zum öffentlichen Betrieb gehören Administratorzugang, Teilnehmerverwaltung, Updates, Sicherungen und Regeln.

## Eine Methode wählen

| Methode                        | Geeignet für                                                | Zuerst prüfen                               |
| ------------------------------ | ----------------------------------------------------------- | ------------------------------------------- |
| Mehrspieler im selben Netzwerk | Kurze Sitzungen zu Hause oder in der Nähe                   | Ob der Host läuft                           |
| Dedicated Server auf Heim-PC   | Kleine Gruppe, die Einrichtung und Verwaltung lernen möchte | Laufzeit, Updates, Sicherungen und Freigabe |
| Realms                         | Spiel auf Einladung mit weniger Verwaltungsarbeit           | Edition, Tarif und Einladungen              |
| Öffentlichem Server beitreten  | Zuerst eine große gemeinsame Welt ausprobieren              | Regeln, Altersangaben und Beitrittsweg      |

Der Ausdruck kostenloser Server bedeutet nicht, dass Software, Hardware, Strom, Bandbreite und Wartung alle kostenlos sind. Wenn du den Server zu Hause betreibst, lege neben den Kosten auch fest, wer reagiert, wenn er ausfällt.

## Einen Java-Edition-Dedicated-Server starten

Java Edition hat offizielle Dedicated-Server-Software. Die offizielle Seite erklärt, dass sie für Java Edition bestimmt ist, Java über die Befehlszeile nutzbar sein muss und die Einrichtung Arbeit erfordern kann.

Folge dieser sichereren Reihenfolge:

1. Beziehe die Server-Software von der offiziellen Quelle.
2. Prüfe Start und Stopp in deiner Umgebung, bevor du sie extern freigibst.
3. Lege fest, wie Weltdaten gesichert werden.
4. Stimme Edition und Version für eine kleine Gruppe ab und teste den Beitritt.
5. Nur wenn externer Zugang nötig ist, konfiguriere Router und Firewall, Teilnehmerverwaltung und Administratorrechte sorgfältig.

## Einen Bedrock-Edition-Dedicated-Server starten

Bedrock besitzt ebenfalls offizielle Dedicated Server Software. Die offizielle Anleitung bietet Software für Windows oder Linux sowie eine beigefügte Nutzungsanleitung. Gehe nicht davon aus, dass Geräte oder Beitrittsschritte mit Java Edition identisch sind, sondern folge der Bedrock-spezifischen Anleitung.

Bei Bedrock können Gerätetypen, Microsoft-Kontoeinstellungen und Online-Einstellungen von Kinderkonten die Verbindung beeinflussen. Beginne mit einer kleinen eingeladenen Gruppe, damit Probleme leichter zu erkennen sind.

## Wann Realms passt

Realms ist eine Option, um Mehrspieler mit eingeladenen Mitgliedern fortzuführen. Anders als eine gewöhnliche Host-Welt, die endet, wenn ihr Besitzer das Spiel verlässt, nutzt es Einladungen und ein Abonnement.

Es ist nicht kostenlos, verringert aber die Arbeit, einen Server selbst freizugeben und zu warten. Prüfe vor dem Abschluss die Editionen der Spieler, den benötigten Tarif und die offiziellen Einladungsschritte.

## Checkliste vor der Serveröffnung

- Sichere Weltdaten regelmäßig.
- Gib Administratorzugang nur Personen, die ihn benötigen.
- Bereite für einen öffentlichen Server Teilnahmeregeln und einen Kontakt zum Betreiber vor.
- Prüfe Kompatibilität und Sicherungen vor einem Update von Spiel oder Server-Software.
- Teile Passwörter, IP-Adressen und Verwaltungsinformationen nicht unnötig.
