자바판과 베드락 에디션 플레이어는 호환되는 서버에서 함께 플레이할 수 있습니다. 서버가 두 에디션의 접속을 모두 받는다면, PC의 Java를 사용하는 친구와 모바일 또는 콘솔의 Bedrock을 사용하는 친구가 같은 서버에서 건축과 모험을 즐길 수 있습니다.

하지만 **모든 Java Edition 서버가 Bedrock Edition을 지원하는 것은 아닙니다.** Java와 Bedrock은 접속 방식이 다르므로 서버 운영진이 Bedrock 플레이어를 받기 위한 방법을 마련해야 합니다. 단순히 “Java 서버”라고 쓰여 있다고 판단하지 말고, 공식 참가 안내에 두 에디션 지원이 명시되어 있는지 확인하세요.

## 자바판과 베드락 에디션은 호환 서버에서 함께 플레이할 수 있습니다

![노트북과 휴대용 기기가 빛나는 길을 따라 같은 블록 세계 서버로 이어지는 모습](/uploads/stories/minecraft-java-bedrock-crossplay-devices.webp)

Java와 Bedrock 크로스플레이를 지원하는 서버에서는 서로 다른 에디션의 플레이어가 같은 서버에 참가할 수 있습니다. 친구들이 다른 에디션을 사용한다는 이유만으로 따로 플레이할 필요는 없습니다.

다만 게임 버전, 서버 규칙, 설치된 기능에 따라 참가 방법이나 사용할 수 있는 조작이 달라질 수 있습니다. 먼저 서버 운영진이 최신 상태로 유지하는 참가 안내를 확인하세요.

## Java 서버가 자동으로 Bedrock과 호환되는 것은 아닙니다

Java와 Bedrock은 별도의 클라이언트와 다른 접속 방식을 사용합니다. Bedrock 플레이어를 받으려면 서버에 호환되는 접속 경로와 설정이 필요합니다. 따라서 Java용 주소만 공개한 서버는 Bedrock에서 직접 접속하지 못할 수 있습니다.

서버에 “Java Edition 지원”만 적혀 있다면 Bedrock 플레이어도 참가할 수 있다고 가정하지 마세요. 그룹에 Bedrock 사용자가 있다면 두 에디션 지원을 분명히 밝힌 서버를 고르거나, 참가 전에 운영진에게 문의하는 편이 좋습니다.

## 지원 서버를 구분하는 세 가지 확인 사항

![블록 세계의 모험가가 지도와 안내판을 확인하고 호환되는 입구를 고르는 모습](/uploads/stories/minecraft-java-bedrock-crossplay-check.webp)

### 1. 공식 안내에 두 에디션이 모두 적혀 있나요?

공식 사이트나 참가 가이드에서 “Java와 Bedrock 지원”, “Java/Bedrock 크로스플레이” 같은 문구를 찾으세요. Java 또는 Bedrock 한쪽만 언급되어 있다면, 다른 에디션도 참가할 수 있다고 가정하지 않는 편이 안전합니다.

### 2. Bedrock용 참가 안내가 있나요?

서버가 Bedrock용 주소, 포트 또는 접속 단계를 제공하는지 확인하세요. Java와 Bedrock이 같은 주소를 쓰는 경우에도 Bedrock에는 다른 포트나 절차가 필요할 수 있습니다. 안내를 찾지 못했다면 지원 여부를 스스로 판단하지 말고 공식 Discord나 다른 공식 채널에서 확인하세요.

### 3. 최신 공지와 규칙을 확인했나요?

지원 에디션, 권장 버전, 참가 조건은 바뀔 수 있습니다. 오래된 소개만 보고 결정하지 말고 공식 사이트, 공지, Discord의 최신 정보까지 확인하세요. 참가 전에 규칙을 읽어 두면 친구들과 합류한 뒤에도 더 원활하게 플레이할 수 있습니다.

## 친구와 플레이하기 전에 준비할 것

- 모든 플레이어가 자기 에디션에 맞게 안내된 접속 대상과 게임 버전을 확인합니다.
- 서버 규칙, 연령 조건, 첫 참가 절차를 읽습니다.
- 텍스처, 조작, 표시처럼 에디션별 차이가 날 수 있는 기능이 있는지 공식 안내에서 확인합니다.

이 세 가지를 먼저 확인하면 한 사람만 접속하지 못하거나, 같은 서버라고 생각했는데 서로 다른 접속 대상을 쓰는 문제를 줄일 수 있습니다.

## Java와 Bedrock 친구와 함께라면 Aceserver

![블록 세계의 공개 서버 로비에서 친구들이 지도를 둘러싸고 만나는 모습](/uploads/stories/minecraft-java-bedrock-crossplay-hub.webp)

Aceserver는 Java Edition 또는 Bedrock Edition에서 참가할 수 있는 무료 공개 Minecraft 서버입니다. 다른 에디션을 쓰는 친구들과 함께 플레이할 서버를 찾고 있다면 좋은 선택지가 될 수 있습니다.

[Aceserver 포털](/ko/)에서 월드 맵과 영상을 먼저 살펴보고, [공식 Discord](https://discord.gg/acsv)에서 최신 참가 안내를 확인하세요. 자세한 규칙과 플레이 정보는 [Aceserver WIKI](https://asv-wiki.acecore.net)에 모여 있습니다.

## 정리

Java와 Bedrock은 서버가 두 에디션의 접속을 지원할 때 함께 플레이할 수 있습니다. 모든 Java Edition 서버가 Bedrock을 지원하는 것은 아니므로, 서버를 고르기 전에 공식 안내에서 두 에디션 지원 여부, Bedrock 참가 방법, 최신 규칙을 확인하세요.

Aceserver는 Java와 Bedrock 플레이어를 모두 받으므로, 다른 에디션을 쓰는 친구들도 같은 서버에서 함께 시작할 수 있습니다.
