친구와 마인크래프트를 시작할 때는 어디서 놀지보다 먼저 모두가 같은 에디션, 즉 **Java 에디션 또는 베드락 에디션**을 쓸 수 있는지 확인하는 편이 빠릅니다. 이 글에서는 내 월드, Realms, 공개 서버를 비교하고 PC·Switch·모바일별 선택 방법을 정리합니다.

## 먼저 확인하기: Java와 베드락은 기본적으로 함께 플레이할 수 없습니다

### Java 에디션은 Java 에디션끼리 플레이합니다

Java 에디션은 주로 Windows, macOS, Linux PC용 에디션입니다. Java 월드, Realms, 서버에는 Java 플레이어가 참가합니다. 친구의 PC에 Minecraft가 있어도 베드락 클라이언트는 기본 상태에서 Java 목적지에 들어갈 수 없습니다.

### 베드락 에디션은 베드락 에디션끼리 플레이합니다

베드락 에디션은 Windows PC, Switch, 스마트폰, 게임 콘솔에서 사용됩니다. 그룹에 Switch 또는 스마트폰 플레이어가 있다면 먼저 모두 베드락을 쓰는지 확인하세요. 공식 [멀티플레이 요구 사항](https://help.minecraft.net/hc/en-us/articles/35930809028749-Requirements-to-Play-Minecraft-Multiplayer-Games)에서도 설치한 에디션이 참가할 곳과 일치해야 한다고 안내합니다.

![PC로 Java 에디션을 사용하는 그룹과 PC·휴대용 게임기·스마트폰으로 베드락 에디션을 사용하는 그룹이 서로 다른 블록 세계에 모인 모습](/uploads/stories/minecraft-play-with-friends-editions.webp)

_친구와 시작할 때는 모두 Java 또는 모두 베드락으로 맞추는 것이 첫 확인이며, 두 그룹은 기본적으로 분리됩니다._

## 참가 전 네 가지 확인

1. **모두 같은 에디션을 맞춥니다.** 그룹이 Java를 할지 베드락을 할지 먼저 정합니다. Java와 베드락 사이의 참가를 기본 조건으로 생각하지 마세요.
2. **게임을 업데이트합니다.** 같은 에디션이라도 버전 차이 때문에 월드가 보이지 않거나 참가하지 못할 수 있습니다.
3. **계정과 온라인 조건을 확인합니다.** Switch 또는 모바일이 포함된 베드락 온라인 플레이나 크로스플레이에서는 모두 Minecraft 안에서 Microsoft 계정에 로그인합니다. Switch는 Nintendo Account와 Nintendo Switch Online도 사용하고, Android는 Google 계정, iPhone과 iPad는 Apple ID를 사용합니다. 계정별 역할은 Minecraft 공식 [계정 및 에디션 표](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft)에서 확인하세요.
4. **아동 계정 설정을 봅니다.** 보호자가 관리하는 멀티플레이 권한이 초대와 참가를 막을 수 있습니다. Microsoft/Xbox 개인정보 설정은 Switch나 모바일에서 플레이할 때도 적용됩니다. 비밀번호를 공유하지 말고 보호자와 함께 개인정보 설정을 확인하세요.

![PC, 휴대용 게임기, 스마트폰을 둘러싼 친구들이 같은 블록 세계, 업데이트, 계정, 보안 설정을 확인하는 모습](/uploads/stories/minecraft-play-with-friends-checklist.webp)

_플레이 전에 에디션, 업데이트, 계정, 아동 계정 설정을 함께 확인하면 참가 문제를 많이 줄일 수 있습니다._

이 항목을 확인했는데도 참가할 수 없다면, [마인크래프트 서버에 들어갈 수 없을 때 확인할 점](/ko/stories/minecraft-server-cannot-join/)을 보고 순서대로 원인을 살펴보세요.

## 내 월드, Realms, 공개 서버 고르기

| 내 월드   | 오늘 밤 소규모로 플레이할 때                       | 월드 주인이 열어 둔 동안 다른 사람이 참가          | 같은 에디션, LAN 또는 초대 조건                    |

### 1. 내 월드: 작은 그룹으로 먼저 시작하기

같은 집이나 같은 장소에 있는 친구라면 LAN으로 내 월드를 여는 것이 쉬운 첫 선택입니다. 베드락 LAN에서는 호환 기기를 같은 로컬 네트워크에 두고, 호스트에서 멀티플레이와 LAN 표시를 켭니다. 공식 [베드락 LAN 안내](https://help.minecraft.net/hc/en-us/articles/35697355112717)는 같은 네트워크에 연결한 뒤 월드를 찾는 방법을 설명합니다.

온라인 친구 초대도 호스트가 열어 둔 월드를 사용합니다. 오늘 둘이서 건축을 시작하거나 그룹이 같은 플레이 방식을 좋아하는지 시험할 때 알맞습니다. 호스트가 월드를 닫으면 다른 사람은 들어갈 수 없으므로 호스트의 플레이 시간을 기준으로 계획하세요.

### 2. Realms: 주인이 없어도 계속 플레이하기

Realms는 Minecraft의 공식 유료 호스팅입니다. 구독이 유효하면 주인이 게임을 실행하지 않아도 초대받은 친구가 들어올 수 있습니다. Java Realms와 베드락 Realms는 분리되어 있으므로 그룹에 맞는 것을 골라야 합니다. Java는 공식 [Java Realms 생성 안내](https://help.minecraft.net/hc/en-us/articles/4409253767821-How-to-Create-a-Minecraft-Java-Edition-Realm), 베드락은 공식 [베드락 Realm 초대 링크 안내](https://help.minecraft.net/hc/en-us/articles/36974952310925-Manage-Invite-Links-for-Minecraft-Bedrock-Edition-Realms)를 확인하세요.

학교, 일, 동아리 일정이 달라도 함께 만든 기지를 조금씩 발전시키고 싶은 친구에게 잘 맞습니다. 누구나 볼 수 있는 곳에 초대 링크를 올리지 말고, 필요 없으면 비활성화하거나 삭제하세요.

### 3. 공개 서버: 커뮤니티에 참가하기

공개 서버는 운영자가 관리하는 온라인 월드입니다. 아직 모르는 플레이어와 건축, 생활, 이벤트를 즐기고 싶은 사람에게 알맞을 수 있습니다. 참가 전에는 해당 서버의 규칙, 지원 에디션과 버전, 연령 조건, 음성 채팅이나 Discord 사용 방식을 확인해야 합니다.

Switch 플레이어는 특히 서버가 안내하는 지원 기기와 참가 방법을 읽어야 합니다. 비공식 접속 방법을 당연하게 생각하지 마세요. 서버가 Java와 베드락 모두를 안내하더라도 실제 조건과 지원 버전은 서버마다 다릅니다.

두 에디션을 모두 받는 서버를 구분하는 방법은 [Java와 베드락을 함께 플레이할 수 있는지](/ko/stories/minecraft-java-bedrock-crossplay/)에서 더 자세히 확인할 수 있습니다.

## Java, 베드락, Switch, 모바일별 시작 방법

### PC에서 Java 에디션을 플레이하는 경우

모두 Java 에디션을 쓴다면 LAN 월드, Java Realm, Java 공개 서버 중에서 고릅니다. 초대 전에 친구가 Java 에디션을 실행했는지와 게임 버전이 맞는지를 확인하면 문제를 줄일 수 있습니다.

### PC에서 베드락 에디션을 플레이하는 경우

Windows PC에서 베드락을 사용하는 플레이어는 Switch와 모바일의 베드락 플레이어와 같은 그룹이 될 수 있습니다. 모두의 시간과 목적에 따라 내 월드의 짧은 세션, 계속하는 Realm, 공개 서버를 고르세요.

### Nintendo Switch에서 플레이하는 경우

Switch의 Minecraft는 베드락 에디션입니다. 인터넷으로 친구와 플레이하려면 Switch 사용자에 연결된 Nintendo Account와 활성화된 Nintendo Switch Online이 필요합니다. 크로스플레이, Minecraft 친구, Realms, 온라인 멀티플레이를 사용하려면 Minecraft 안에서 Microsoft 계정에도 로그인하고 연결합니다. Nintendo Account/Nintendo Switch Online과 Microsoft 계정은 역할이 다르므로 하나가 다른 하나를 대신하지 않습니다.

가까이 있는 Switch끼리의 로컬 통신에는 Nintendo Switch Online이 필요 없지만, 인터넷을 통한 참가와는 다른 방식입니다. 멀리 있는 모바일·PC 친구와 플레이하려면 모두 베드락을 사용하고, 각자의 Microsoft 계정과 Switch 쪽 온라인 구독을 확인하세요.

### 스마트폰 또는 태블릿에서 플레이하는 경우

모바일 Minecraft도 베드락 에디션입니다. Android는 Google 계정을, iPhone과 iPad는 Apple ID를 사용합니다. 또한 크로스플레이, Minecraft 친구, Realms, 온라인 멀티플레이에는 Minecraft 안에서 Microsoft 계정에 로그인합니다. 스마트폰과 태블릿에는 Nintendo Switch Online 같은 콘솔 온라인 구독이 필요하지 않습니다. 앱 구매비와 데이터 통신료는 별도입니다. 집 Wi-Fi에서 짧은 LAN 세션을 먼저 시험하면 Realms나 공개 서버로 넘어가기 전에 문제를 찾기 쉽습니다.

## Switch와 모바일의 계정 및 온라인 구독

Switch와 모바일은 모두 베드락 에디션입니다. 모두가 같은 최신 일반 베드락 버전을 사용하고 Microsoft 계정에 로그인하면 Switch, Android, iPhone/iPad, Windows PC의 베드락 플레이어끼리 크로스플레이할 수 있습니다. Java 에디션 친구는 표준 게임 기능만으로 같은 월드에 참가할 수 없습니다.

| 기기                         | 플랫폼 계정      | 크로스플레이와 온라인 플레이용 Minecraft 내 계정 | 추가 온라인 구독                                                                                                       |
| ---------------------------- | ---------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Nintendo Switch              | Nintendo Account | Microsoft 계정 로그인 및 연결                    | 인터넷 온라인 플레이에는 Nintendo Switch Online이 필요합니다. 가까이 있는 Switch끼리의 로컬 통신에는 필요하지 않습니다 |
| Android 스마트폰 또는 태블릿 | Google 계정      | Microsoft 계정 로그인                            | 콘솔 온라인 구독이 필요하지 않습니다                                                                                   |
| iPhone 또는 iPad             | Apple ID         | Microsoft 계정 로그인                            | 콘솔 온라인 구독이 필요하지 않습니다                                                                                   |

Switch와 모바일에서 Microsoft 계정은 게임을 받는 데 쓰는 계정과 별개이며, 친구, 크로스플레이, Realms, 온라인 멀티플레이를 가능하게 합니다. 자세한 내용은 Minecraft 공식 [계정 표](https://help.minecraft.net/hc/en-us/articles/19615552270221-Accounts-Required-to-Play-Minecraft), [Switch 연결 절차](https://help.minecraft.net/hc/en-us/articles/4408894129933-Sign-in-to-Minecraft-with-a-Microsoft-Account-on-Nintendo-Switch), [모바일 로그인 절차](https://help.minecraft.net/hc/en-us/articles/31514831369869), 닌텐도의 [온라인 플레이 설명](https://support.nintendo.com/jp/nso/services/onlineplay/index.html)을 확인하세요.

### 베드락 친구 초대하기

1. 모두가 최신 일반 베드락 버전을 시작하고 Minecraft 안에서 Microsoft 계정에 로그인합니다. 친구를 찾을 때는 표시 이름만 보지 말고 Xbox 게이머태그를 확인하세요.
2. 호스트는 대상 월드 설정에서 멀티플레이 게임을 켜고, 참가자 접근을 친구 또는 친구의 친구로 설정한 뒤 월드를 엽니다.
3. 호스트는 게임 안에서 소셜을 열고 플레이에 초대를 선택하며, 초대받은 사람은 받은 초대를 수락합니다. 다른 장소에서 Switch로 참가하는 사람은 Nintendo Switch Online이 활성화되어 있는지도 확인해야 합니다.

화면 이름과 알림은 기기와 업데이트에 따라 다를 수 있습니다. 헷갈리면 Minecraft 공식 [베드락 월드 초대 절차](https://help.minecraft.net/hc/en-us/articles/32899440702477)를 따르세요.

### 아동 계정의 보호자 설정

Xbox 본체가 없어도 Microsoft/Xbox 보호자 설정은 Switch와 모바일의 Minecraft에 적용됩니다. 보호자는 자녀의 Microsoft 계정을 선택하고 적어도 다음을 확인합니다.

- **멀티플레이 게임 참가 / Xbox에서 멀티플레이 참가:** 허용하면 멀티플레이, Realms, 다른 서버에 참가할 수 있습니다.
- **크로스 네트워크 플레이 참가:** 허용하면 Switch와 모바일을 포함한 다른 게임 플랫폼의 사람과 플레이할 수 있습니다.
- **친구 추가 및 다른 사람 팔로우:** 허용하면 Minecraft 친구 목록에서 친구를 찾아 초대할 수 있습니다.
- **음성, 텍스트, 초대 연락:** 가정의 기준에 맞춰 허용 범위를 정합니다.

변경한 뒤에는 Minecraft에서 로그아웃하고 게임을 종료한 다음 다시 시작합니다. Switch와 스마트폰의 보호자·사용 제한은 별개이므로 Microsoft 설정만으로 해결되지 않으면 보호자와 기기 쪽도 확인하세요. 항목 이름은 바뀔 수 있으므로 Minecraft 공식 [아동 계정 멀티플레이 설정](https://help.minecraft.net/hc/en-us/articles/24302916594701-Managing-Multiplayer-Game-Access-for-a-Child-Account-in-Minecraft)을 우선하세요.

## Switch 또는 모바일에서 연결할 수 없을 때

다음 순서로 확인하면 계정 문제와 네트워크 문제를 구분하기 쉽습니다.

1. **에디션과 업데이트:** 모두 베드락이며 같은 최신 일반 버전을 쓰는지 확인합니다. 프리뷰나 오래된 버전이 섞였다면 먼저 업데이트하고 일반 버전으로 맞춥니다.
2. **호스트 월드 설정:** 멀티플레이 게임과 참가자 접근이 켜져 있는지, 개인 월드라면 호스트가 온라인인지 확인합니다. Realms라면 소유자의 구독과 Realm이 열려 있는지도 확인합니다.
3. **Microsoft 계정과 보호자 설정:** 각자가 올바른 Microsoft 계정에 로그인했는지, 아동 계정에서 멀티플레이·크로스 네트워크·친구 추가가 허용되었는지 확인합니다.
4. **Switch 전용 구독:** 인터넷으로 플레이하는 Switch 참가자는 활성 Nintendo Account와 Nintendo Switch Online이 필요합니다. 모바일에는 이 구독이 필요하지 않습니다.
5. **연결:** Minecraft와 기기를 재시작하고 평소 인터넷 연결로 시험합니다. 참가하는 사람은 라우터 포트를 임의로 열 필요가 없습니다. VPN이나 사용자 지정 DNS를 바꿨다면 시험 전에 원래 설정으로 되돌립니다.

“멀티플레이가 비활성화되었습니다”라고 표시되면 먼저 Microsoft/Xbox 개인정보 또는 보호자 설정을 확인하세요. 초대가 오지 않거나 월드가 보이지 않으면 에디션, 호스트 설정, Microsoft 계정을 확인합니다. 그래도 연결할 수 없다면 Minecraft 공식 [베드락 멀티플레이 연결 문제 해결](https://help.minecraft.net/hc/en-us/articles/4409236107789-Minecraft-Bedrock-Edition-Multiplayer-Connectivity-Issues)과 [마인크래프트 서버에 들어갈 수 없을 때 확인할 점](/ko/stories/minecraft-server-cannot-join/)을 참고하세요. 도움을 요청할 때는 에디션, 기기, 게임 버전, 표시된 오류, 시도한 시간을 전하고 비밀번호나 인증 코드는 절대 공유하지 마세요.

## 빠르게 결정하는 법

- **그룹에 Switch 또는 모바일 플레이어가 있다면:** 모두 베드락을 사용합니다.
- **모두 PC의 Java 에디션을 사용한다면:** Java 월드, Realm, 서버를 고릅니다.
- **호스트가 없어도 계속하고 싶다면:** Realms를 고려합니다.
- **새 플레이어를 만나고 싶다면:** 규칙과 지원 에디션을 읽고 공개 서버를 고릅니다.

일부 서버는 Java와 베드락 크로스플레이를 위한 자체 추가 시스템을 제공합니다. 이것은 기기만으로 보장되는 기본 기능이 아니므로, 참가할 곳의 공식 안내에서 현재 지원 상황을 확인하세요.

그룹이 계속 열어 둘 월드를 직접 관리하고 싶다면, LAN·전용 서버·Realms 중 선택하기 전에 [무료 마인크래프트 서버를 만드는 방법](/ko/stories/minecraft-server-setup/)을 읽어 보세요.

## Aceserver에서 친구와 플레이하기

공개 서버를 고른다면 먼저 [Aceserver 포털](/ko/)에서 현재 입구를 확인하고, [공식 Discord](https://discord.gg/acsv)와 [공식 WIKI](https://asv-wiki.acecore.net)에서 최신 참가 안내와 규칙을 읽으세요. 이 글은 바뀔 수 있는 접속 정보를 복사하지 않으며, 공식 안내를 기준으로 합니다.

친구를 초대할 때는 같은 에디션인지 확인하고, 참가 전에 규칙을 읽으며, 계정 정보를 공유하지 않는 것부터 알리면 좋습니다. 먼저 공개 서버를 비교하고 싶다면 [Minecraft 서버 선택 방법](/ko/stories/minecraft-server-osusume/)을 참고하세요.
