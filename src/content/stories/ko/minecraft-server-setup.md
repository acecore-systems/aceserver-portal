친구와 Minecraft를 하는 방법은 하나가 아닙니다. 호스팅 요금 없이 시작하고 싶은지, 모두 집에 있을 때만 플레이해도 되는지, 언제든 들어갈 수 있는 월드가 필요한지에 따라 맞는 방법이 달라집니다.

이 글은 Java와 Bedrock Edition을 먼저 선택한 뒤, 서버 소프트웨어의 무료 범위, 집 PC의 전용 서버, Realms 중에서 고르는 기준을 설명합니다. 모든 플레이어가 정식 게임을 보유하고 있다는 전제입니다.

## 먼저 정할 세 가지

### 참가자의 에디션과 기기

공식 전용 서버 소프트웨어는 Java Edition과 Bedrock Edition에 각각 따로 제공됩니다. 시작 전에 모두 PC, 휴대전화, 콘솔 중 무엇을 쓰는지와 Java 또는 Bedrock 중 무엇을 쓰는지 확인하세요.

### 월드가 열려 있어야 하는 시간

호스트 월드나 집 PC는 보통 호스트가 실행 중일 때만 접속할 수 있습니다. 호스트가 없을 때도 다른 사람이 들어와야 한다면 항상 켜 두는 방식과 운영 부담을 계획해야 합니다.

### 누가 참가할 수 있는가

친구 몇 명만을 위한 비공개 월드와 누구나 들어올 수 있는 공개 월드는 필요한 보호 조치가 다릅니다. 공개 운영에는 관리자 권한, 참가자 관리, 업데이트, 백업, 규칙이 포함됩니다.

## 방법 선택 기준

| 방법                       | 알맞은 경우                                  | 먼저 확인할 것                          |
| -------------------------- | -------------------------------------------- | --------------------------------------- |
| 같은 네트워크의 멀티플레이 | 집이나 가까운 곳에서 짧게 플레이             | 호스트가 실행 중인지                    |
| 집 PC 전용 서버            | 소규모 그룹으로 설정과 관리를 배우고 싶을 때 | PC 가동 시간, 업데이트, 백업, 공개 범위 |
| Realms                     | 관리 작업을 줄인 초대형 플레이               | 에디션, 요금제, 초대                    |
| 공개 서버 참가             | 먼저 큰 공유 월드를 경험하고 싶을 때         | 규칙, 연령 안내, 참가 방법              |

무료 서버라는 말이 소프트웨어, 하드웨어, 전기, 회선, 유지 관리가 모두 무료라는 뜻은 아닙니다. 집에서 실행한다면 비용뿐 아니라 서버가 멈췄을 때 누가 대응할지도 정해 두세요.

## Java Edition 전용 서버 시작하기

Java Edition에는 공식 전용 서버 소프트웨어가 있습니다. 공식 페이지는 이것이 Java Edition용이며 명령줄에서 Java를 사용할 수 있어야 하고 설정에 작업이 필요할 수 있다고 안내합니다.

다음의 더 안전한 순서를 따르세요.

1. 공식 출처에서 서버 소프트웨어를 받습니다.
2. 외부에 공개하기 전에 자신의 환경에서 시작과 종료를 확인합니다.
3. 월드 데이터 백업 방법을 정합니다.
4. 소규모 그룹의 에디션과 버전을 맞추고 접속을 테스트합니다.
5. 외부 접속이 필요한 경우에만 라우터와 방화벽, 참가자 관리, 관리자 권한을 신중하게 설정합니다.

## Bedrock Edition 전용 서버 시작하기

Bedrock에도 공식 Dedicated Server Software가 있습니다. 공식 안내는 Windows 또는 Linux용 소프트웨어와 포함된 사용 안내서를 제공합니다. 기기나 참가 절차가 Java Edition과 같다고 생각하지 말고 Bedrock 전용 안내를 따르세요.

Bedrock에서는 기기 종류, Microsoft 계정 설정, 아동 계정의 온라인 설정이 접속에 영향을 줄 수 있습니다. 문제를 쉽게 진단할 수 있도록 처음에는 초대한 소규모 그룹으로 시작하세요.

## Realms가 알맞은 경우

Realms는 초대한 멤버와 멀티플레이를 계속하기 위한 선택지입니다. 소유자가 게임을 나가면 끝나는 일반 호스트 월드와 달리 초대와 구독 방식으로 운영됩니다.

무료는 아니지만 서버를 직접 공개하고 유지하는 작업을 줄여 줍니다. 구독하기 전에 플레이어 에디션, 필요한 요금제, 공식 초대 절차를 확인하세요.

## 서버를 열기 전 점검표

- 월드 데이터를 정기적으로 백업합니다.
- 필요한 사람에게만 관리자 권한을 줍니다.
- 공개 서버라면 참가 규칙과 운영자에게 연락할 방법을 준비합니다.
- 게임이나 서버 소프트웨어를 업데이트하기 전에 호환성과 백업을 확인합니다.
- 비밀번호, IP 주소, 관리 정보를 불필요하게 공유하지 않습니다.

현재 안내와 다운로드는 [Java Edition 서버 다운로드 페이지](https://www.minecraft.net/en-us/download/server), [Dedicated Server Software 안내](https://help.minecraft.net/hc/en-us/articles/4408873961869-Minecraft-Dedicated-and-Featured-Servers-FAQ-), [Bedrock Realms 참가 안내](https://help.minecraft.net/hc/en-us/articles/4410386197133-Join-a-Minecraft-Bedrock-Edition-Realm)에서 확인하세요.
