마인크래프트 서버에 접속할 수 없을 때는 무작정 여러 번 재접속하기보다 게임 에디션, 서버 자체의 안내, 계정, 네트워크로 원인을 나누어 보는 편이 좋습니다. 이 글의 앞부분은 어느 서버에나 적용되는 공통 확인 절차입니다. Aceserver 전용 안내는 뒤에서 따로 다룹니다.

그룹에 Switch나 스마트폰 플레이어가 있다면 참여 방법을 정하기 전에 [친구와 마인크래프트를 함께 플레이하는 방법](/ko/stories/minecraft-play-with-friends/)에서 에디션과 계정 조건을 확인하세요.

## 먼저 접속 문제와 접속 후의 불안을 나누기

- **접속할 수 없음:** 오류 표시, 에디션, 버전, 계정, 네트워크, 서버의 이용 가능 상태를 확인합니다.
- **접속했지만 무엇을 해야 할지 모름:** 규칙, 처음 갈 곳, 공식 문의처를 확인합니다. 접속 직후 길을 잃지 않는 것도 계속 참여하기 위한 중요한 준비입니다.

두 가지는 서로 다른 문제입니다. 첫 번째를 해결하는 동안 두 번째 불안을 참을 필요는 없습니다.

## 5분 안에 하는 공통 확인 순서

1. 표시된 오류, 접속을 시도한 시각, 사용 중인 기기를 기록합니다. 스크린샷도 좋습니다.
2. 서버 공식 안내에서 점검, 모집 중단, 허용 목록, 지원 에디션을 확인합니다.
3. 서버 주소, 필요한 포트, 게임 버전을 안내와 한 글자씩 비교합니다.
4. Minecraft와 기기를 다시 시작하고 일반 정식 버전을 사용 중인지, 테스트·스냅샷·미리 보기 버전이 아닌지 확인합니다.
5. 해결되지 않으면 계정, 권한, 네트워크 순서로 하나씩 확인합니다. 여러 설정을 동시에 바꾸면 원인을 찾기 어렵습니다.

## Java, 베드락, Switch에서 다른 점

### Java Edition

Java Edition은 Windows, macOS, Linux에서 이용할 수 있습니다. 서버가 Java용 안내를 제공한다면 런처에서 지정된 일반 정식 버전을 선택하고 멀티플레이에서 서버 주소를 입력합니다. 주소는 IP 주소일 수도 있고 URL 형식의 호스트 이름일 수도 있습니다.

특히 서버가 요구하는 게임 버전과 MOD 또는 런처 설정을 확인해야 합니다. 바닐라 서버는 테스트 버전이나 불필요한 MOD를 거부할 수 있습니다. 먼저 공식 안내에 나온 일반 버전으로 시도하고, 추가 요소는 서버가 명시한 경우에만 넣으세요.

### Bedrock Edition

Bedrock Edition은 Windows, 모바일 기기, 게임 콘솔 등 지원되는 플랫폼에서 사용합니다. Java와 베드락은 서로 다른 온라인 서버 체계를 사용하므로, 서버가 두 에디션을 모두 지원한다고 명시하지 않는 한 다른 에디션으로는 접속할 수 없습니다.

베드락에서는 게임 업데이트, Microsoft 계정 로그인, 멀티플레이 허용 여부를 확인합니다. 개인 월드에 친구를 초대하는 경우에는 그 월드 자체에서도 멀티플레이를 허용해야 합니다. 공개 서버에 들어갈 때는 그 서버가 베드락용으로 공개한 주소와 포트만 사용하세요.

### Nintendo Switch

Nintendo Switch의 Minecraft는 Bedrock Edition이므로 Java 전용 안내는 사용할 수 없습니다. Minecraft 온라인 멀티플레이에는 Microsoft 계정 로그인과 유효한 Nintendo Switch Online 가입이 필요합니다.

Switch에서는 게임 업데이트, 로그인한 Microsoft 계정, Nintendo Switch Online, 보호자 멀티플레이 제한을 차례로 확인합니다. 서버 추가 화면과 접속 절차는 기기에 따라 다를 수 있으므로, 대상 서버가 Switch용으로 공식 안내한 방법만 사용하세요. 접속을 위해 익숙하지 않은 DNS 변경이나 포트 개방을 시도할 필요는 없습니다.

## 서버 자체의 안내와 일치시키기

아래 항목은 반드시 접속하려는 서버의 공식 안내에서 확인합니다. 다른 서버에서 작동했던 설정을 그대로 사용하지 마세요.

| 확인할 항목 | 자주 생기는 불일치                                |
| ----------- | ------------------------------------------------- |
| 지원 에디션 | 베드락에서 Java 안내를 사용하거나 그 반대         |
| 게임 버전   | 오래된 버전, 스냅샷, 미리 보기 버전으로 접속      |
| 주소와 포트 | 예전 공지, 오타, 다른 서버 정보를 사용            |
| 참여 조건   | 허용 목록, 연령 조건, 규칙 확인, 모집 중단을 놓침 |
| 서버 상태   | 점검, 장애, 재시작 중 계속 접속 시도              |

서버가 Java와 베드락 모두 접속 가능하다고 해도 접속 대상과 절차가 같지는 않을 수 있습니다. 먼저 자신의 에디션을 고르고, 그 에디션의 최신 안내를 따르세요.

## 계정, 권한, 네트워크 확인하기

멀티플레이가 비활성화되었다거나 권한 오류라는 메시지가 보이면 서버 주소가 아니라 계정 설정이 원인일 수 있습니다. 올바른 Microsoft 계정으로 로그인했는지, 멀티플레이가 허용되었는지, 자녀 또는 가족 계정 설정에 제한이 없는지 확인합니다.

네트워크 오류나 시간 초과가 나면 먼저 Minecraft와 기기를 다시 시작하고 평소 인터넷 연결이 안정적인지 확인합니다. 학교·시설·회사 네트워크, VPN, 사용자 DNS는 온라인 게임을 제한할 수 있습니다. 서버에 참여하는 사람은 라우터 포트를 무작정 열 필요가 없습니다. 사용자 DNS와 포트 설정은 Minecraft 접속에 간섭할 수 있으므로 변경했다면 원래 상태로 되돌린 뒤 확인하세요.

## 표시된 오류로 다음 단계를 정하기

| 메시지 또는 상황         | 먼저 확인할 것                        | 먼저 하지 말 것                                 |
| ------------------------ | ------------------------------------- | ----------------------------------------------- |
| 버전이 다름              | 서버 지정 버전과 자신의 일반 버전     | 테스트 버전이나 다른 에디션으로 변경            |
| 로그인 또는 인증 오류    | 의도한 Microsoft 계정과 로그인 상태   | 서버 운영진을 포함해 누구에게도 비밀번호 보내기 |
| 시간 초과 또는 접속 불가 | 공식 점검·장애 안내와 자신의 네트워크 | 여러 설정을 바꾸며 반복 재접속                  |
| 권한 또는 참여 조건 오류 | 규칙, 허용 목록, 연령 조건, 초대 상태 | 다른 계정으로 조건을 우회하려 하기              |

오류 이름이나 코드가 표시되면 그것도 기록하세요. 기기, 에디션, 게임 버전, 시각, 오류 이름이 있으면 공식 지원이나 서버 팀이 상황을 이해하기 쉽습니다.

## 접속 후에도 편하게 계속 플레이하기 위한 세 가지 행동

1. **먼저 규칙을 읽기:** 건축 가능 구역, 토지 보호, 채팅, 아이템, 월드 이동 방식은 서버마다 다릅니다. 스폰 지점 표지판, 공식 사이트, WIKI, Discord 고정 메시지를 확인합니다.
2. **작은 첫 목표 정하기:** 월드 구경, 자원 수집, 거점 후보 찾기처럼 작은 목표부터 시작하면 첫 방문에 정보가 너무 많아지는 일을 줄일 수 있습니다.
3. **공식 연락처 저장하기:** 접속 후 문제가 생겨도 추측이나 비공식 방법에 의존하지 않고 올바른 안내를 확인할 수 있습니다.

이 세 가지는 처음 참여하는 사람뿐 아니라 오랜만에 돌아오는 사람에게도 도움이 됩니다. 접속 성공을 끝으로 보지 말고, 계속 플레이할 수 있는 안전한 입구를 만드세요.

## Aceserver를 이용하는 경우에만 확인할 점

여기부터는 일반적인 접속 방법이 아니라 Aceserver 안내입니다. Aceserver 포털은 Java와 베드락 모두 참여할 수 있다고 안내하지만, 실제 접속 대상, 포트, Switch 절차, 서버 상태, 규칙은 바뀔 수 있습니다. 앞의 일반적인 설명이 아니라 아래 공식 안내를 기준으로 확인하세요.

1. [Aceserver 포털](/ko/)에서 현재 참여 입구와 공지를 확인합니다.
2. [공식 Discord](https://discord.gg/acsv)에서 최신 점검 및 참여 안내를 확인합니다.
3. [공식 WIKI](https://asv-wiki.acecore.net)에서 게임 내 규칙과 각 월드 안내를 확인합니다.

그래도 접속할 수 없다면 Java인지 베드락인지, 사용 기기(Switch라면 그 사실), 게임 버전, 표시된 오류, 시도한 시각을 함께 알려 주세요. 계정 비밀번호나 인증 코드를 공유할 필요는 없습니다.
