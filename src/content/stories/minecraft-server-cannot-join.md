マイクラサーバーに入れないときは、表示されたエラーとサーバーの案内を照らし合わせ、エディション・バージョン・参加条件を確認してから、アカウントや通信を切り分けます。何度も接続を試す前に、一度に一つずつ確認するのがポイントです。

この記事では、Java版・統合版・Switchで異なる点、エラー別の確認先、Aceserverを利用する場合の公式案内を順に紹介します。Switchやスマホから参加する前の条件を整理したい場合は、[マイクラで友達と遊ぶ方法](/stories/minecraft-play-with-friends/)も確認してください。

「マルチプレイが無効」はアカウントの許可、「タイムアウト」は接続先・稼働状況・通信を調べる手がかりです。同じ対処で解決するとは限りません。画面の操作に迷ったら、Minecraft公式の[サーバー参加手順](https://www.minecraft.net/en-us/article/how-play-minecraft-server)で自分のエディションの入力画面を確認し、以下の項目を順に見ていきましょう。

## まず確認：接続できないのか、参加後に困っているのか

- **サーバーに接続できない**: エラー表示、エディション、バージョン、参加条件、アカウント、通信、サーバー側の公開状況を確認します。
- **接続できたが、何をすればよいか分からない**: ルール、最初に行く場所、困ったときの連絡先を確認します。

接続の問題と、参加後の不安は別のものです。まずは接続できない原因を切り分け、入れた後はサーバーの案内を確認しましょう。

## 最初に行う共通チェック

1. エラー文、接続した時刻、使っている機種を控えます。画面のスクリーンショットを残しても構いません。
2. 参加したいサーバーの公式案内で、メンテナンス・募集停止・ホワイトリスト・対応エディションを確認します。
3. サーバーアドレス、必要なポート、ゲームのバージョンを、案内と一文字ずつ照らし合わせます。
4. Minecraftと本体を再起動し、通常版を起動しているか、テスト版・プレビュー版ではないかを確認します。
5. 直らない場合は、アカウント・権限・通信を一つずつ確認します。複数の設定を同時に変えると、原因を特定しにくくなります。

## Java版・統合版・Switchで確認すること

### Java版

Java版はWindows、macOS、Linux向けのエディションです。サーバーがJava版用の場合は、案内された通常リリースをランチャーで選び、「マルチプレイ」からサーバーアドレスを入力します。接続先にはIPアドレスやホスト名を使います。WebページのURLとは異なるため、サーバーが案内するアドレスを入力してください。

特に確認したいのは、サーバーが指定するゲームのバージョンと、MOD・ランチャーの設定です。サーバーがバニラ用なのに、不要なMODやテスト版を起動していると参加できないことがあります。まず案内どおりの通常版で試し、追加要素はサーバーが明示している場合だけ使いましょう。

### 統合版（Bedrock）

統合版はWindows、スマートフォン、ゲーム機などで使われるエディションです。Java版と統合版はオンライン接続の仕組みが異なるため、両対応と案内されていないサーバーには、もう一方のエディションから参加できません。

ゲームの更新、Microsoftアカウントへのサインイン、マルチプレイの許可を確認してください。自分のワールドに友達を招く場合は、ワールド側のマルチプレイ設定も確認します。公開サーバーに参加するときは、そのサーバーが統合版用として案内しているアドレスとポートを使ってください。

### Nintendo Switch

Nintendo Switch版のMinecraftは統合版です。Java版専用の案内では参加できません。Minecraftのオンラインマルチプレイには、Microsoftアカウントへのサインインと、有効なNintendo Switch Onlineへの加入が必要です。

ゲームの更新状況、サインインしているMicrosoftアカウント、Nintendo Switch Online、保護者によるマルチプレイ制限を順に確認します。サーバーの追加画面や参加方法は機種によって異なるため、任意のサーバーへ接続する場合は、そのサーバーがSwitch向けに案内している手順を使いましょう。接続のために、よく分からないDNS変更やポート開放を試す必要はありません。

## サーバーの案内と入力内容を照らし合わせる

参加したいサーバーの公式案内を確認し、別のサーバーで使えた設定を流用しないようにしましょう。

| 確認する項目       | よくある行き違い                                         |
| ------------------ | -------------------------------------------------------- |
| 対応エディション   | Java版用の案内を統合版で使う、またはその逆               |
| ゲームのバージョン | 古い版、スナップショット、プレビュー版で接続する         |
| アドレス・ポート   | 古い告知、入力ミス、別サーバーの情報を使う               |
| 参加条件           | ホワイトリスト、年齢条件、ルール確認、募集停止を見落とす |
| サーバーの状態     | メンテナンス、障害、再起動中に何度も接続する             |

「Java版・統合版の両方から参加できる」と案内されていても、接続先や手順が同じとは限りません。参加するエディションを決め、そのエディション向けの案内に従ってください。

## アカウント・権限・通信を確認する

「マルチプレイが無効です」「権限がありません」と表示された場合は、サーバーアドレスだけでなくアカウント側の設定も確認します。Microsoftアカウントに正しくサインインしているか、マルチプレイが許可されているか、子ども用アカウントやファミリー設定に制限がないかを見てください。

通信エラーやタイムアウトでは、Minecraftと本体を再起動し、普段のインターネット接続が安定しているかを確かめます。学校・施設・会社のネットワーク、VPN、独自DNSなどを使っている場合、その環境がオンラインゲームを制限していることがあります。

参加する側が、手当たり次第にルーターのポートを開放する必要はありません。独自のDNSやポート設定を変更している場合は、Minecraftの接続に影響していないかを確認し、必要に応じて元の設定に戻してから試してください。

## エラー表示から確認先を選ぶ

| 表示や状況                 | まず確認すること                             | 先にしないこと                           |
| -------------------------- | -------------------------------------------- | ---------------------------------------- |
| バージョンが違う           | サーバーの指定版と、自分が起動している通常版 | テスト版や別エディションへの切り替え     |
| サインイン・認証エラー     | 正しいMicrosoftアカウントとサインイン状態    | パスワードを他人や運営に送ること         |
| タイムアウト・接続できない | 公式の障害・メンテナンス案内と自分の回線     | 何度も再接続し、設定を同時に変えること   |
| 権限・参加条件のエラー     | ルール、ホワイトリスト、年齢条件、招待状態   | 別アカウントで条件を回避しようとすること |

エラー名が表示された場合は、その名前も控えてください。サーバー運営や公式サポートへ相談するときは、機種・エディション・ゲームのバージョン・接続した時刻・エラー名を伝えると、状況を説明しやすくなります。

## 参加後に確認する3つのこと

1. **最初にルールを読む**: 建築できる場所、土地保護、チャット、アイテム、ワールド移動の扱いはサーバーごとに異なります。スポーン地点の案内板、公式サイト、WIKI、Discordの固定メッセージを確認します。
2. **最初の目標を一つ決める**: ワールドを見学する、資源を集める、拠点候補を探すなど、小さな目標から始めると、初回に情報を整理しやすくなります。
3. **困ったときの連絡先を保存する**: 接続後に問題が起きたとき、公式の案内先を確認できるようにしておきます。

この3つは、初めて参加する人だけでなく、久しぶりに戻る人にも役立ちます。接続後は、サーバーの案内に沿って遊び始めましょう。

## Aceserverを利用する場合の確認先

ここからは一般的な接続方法ではなく、Aceserverの参加案内です。Aceserverの公式ポータルでは、Java版・統合版のどちらからでも参加できることが案内されています。実際の接続先、ポート、Switchでの手順、稼働状況、ルールは更新されることがあるため、参加前に以下の公式案内を確認してください。

1. [エースサーバーポータル](/)で、参加入口とお知らせを確認します。
2. [公式Discord](https://discord.gg/acsv)で、メンテナンスや参加に関する案内を確認します。
3. [公式WIKI](https://asv-wiki.acecore.net)で、ゲーム内のルールや各ワールドの案内を確認します。

![ポータル、公式の案内板、ガイドブックを順にたどって参加情報を確認するブロック調のイメージ](/uploads/stories/minecraft-server-cannot-join-official-guidance.webp)

それでも接続できない場合は、「Java版か統合版か」「使っている機種（Switchならその旨）」「ゲームのバージョン」「表示されたエラー」「試した時刻」を添えて相談してください。アカウントのパスワードや認証コードを共有する必要はありません。

## 公式情報を優先して切り分ける

ゲームや本体の画面、オンラインサービスの条件は変わることがあります。操作方法や利用条件を確認するときは、Minecraftと各プラットフォームの公式案内を優先してください。

- [Minecraft統合版のマルチプレイ接続トラブルシューティング](https://help.minecraft.net/hc/en-us/articles/4409236107789-Minecraft-Bedrock-Edition-Multiplayer-Connectivity-Issues)
- [Minecraft Java版でオンラインサーバーに参加する方法](https://help.minecraft.net/hc/en-us/articles/32899741198989-Play-Minecraft-Java-Edition-Online-in-a-Multiplayer-Server)
- [Nintendo Switch Onlineのオンラインプレイ案内](https://support.nintendo.com/jp/nso/services/onlineplay/index.html)
